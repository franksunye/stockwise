## 🚀 3. 下季度专项：行为合伙人 (2026 Q2 Focus)

**代号**: `Project Echo` (行为回声)
**商业价值**: 从“预测器”向“教练员”的身份跨越，建立个人投资数据的“护城河”。

### 专项 A：持仓审计魔镜 (Personalized Portfolio Coach)
- **目标**: 实现基于买入成本的动态风控建议。
- **关键交付**:
  - `UserPortfolio` 数据加密存储层（支持手动输入/模拟同步）。
  - **个性化止损建议算法**: “你的当前持仓在当前量能下，安全度较买入时下降了 15%”。
  - **持仓/计划偏差审计**: “你今天的操作偏离了昨日 AI 计划 2%，请警惕多巴胺干扰”。

### 专项 B：冲动防护与行为控制 (Impulse Guard)
- **目标**: 介入盘中“非理性”窗口。
- **关键交付**:
  - **盘中摩擦力设计**: 搜索非自选股时强制 60s “冷静窗口”。
  - **风险问答锁**: 解锁交易计划前需回答 3 个关键风险评估问题。

### 专项 C：Silent Math 视觉钩子与游戏化 (Viral Growth)
- **目标**: 降维打击，实现朋友圈/社交媒体的高频传播。
- **关键交付**:
  - **财运/投资宜忌系统**: 计算每日市场资金流向 + 策略共振，转化为“宜/忌/财神位”趣味视觉长图。
  - **视觉引擎**: 自动化生成符合小红书审美的“个股能量槽”、“市场情绪天气”。
