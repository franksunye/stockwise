- PWA 是什么？
    - PWA（Progressive Web App）是一种网页应用，它可以通过浏览器安装到桌面，支持离线使用，并且可以接收通知。
    - PWA 需要用户手动安装，安装后可以在桌面上找到图标，点击图标可以直接打开应用。
    - PWA 需要用户手动授权通知，授权后可以通过通知接收消息。
    - PWA 需要用户手动刷新，刷新后可以获取最新数据。
    - PWA 需要用户手动更新，更新后可以使用新功能。
- iOS 用户如何安装PWA？
    - 打开 Safari 浏览器
    - 访问 https://stockwise.app
    - 点击分享按钮
    - 选择添加到主屏幕
- iOS 用户如何接收通知？
    - 打开 Safari 浏览器
    - 访问 https://stockwise.app
    - 点击分享按钮
    - 选择添加到主屏幕
    - 点击通知图标
    - 选择允许通知
