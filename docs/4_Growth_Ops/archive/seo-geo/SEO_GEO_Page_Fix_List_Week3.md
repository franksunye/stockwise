## 修复模板（每页都按此执行）

1. 标题：包含主关键词 + 场景词。
2. 首段：前 120 字给结论，不写空泛背景。
3. TL;DR：3 条以内，单条单观点。
4. 来源块：至少 2 条来源 + 日期 + 主张范围。
5. 内链：至少 3 条（同类 2 + 转化 1）。
6. 边界声明：固定模板，避免收益承诺。
