# Android 用户如何安装？

Android 是 PWA 的原生主场，支持最为流畅。

1. **Chrome 访问**：使用 Chrome 浏览器打开 \`ziso.cc\`。
2. **一键安装**：点击地址栏右侧的“安装应用”提示，或在菜单中选择“安装到桌面”。

**华为/小米/OPPO 特别提醒**：
若系统拦截，请在手机“设置”中允许 Chrome 浏览器的“创建桌面快捷方式”权限。
