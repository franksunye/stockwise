# iOS 用户如何安装？

在 iPhone/iPad 上，只需两步即可将 ZISO AI 转化为全屏 App。

1. **Safari 访问**：打开 Safari 浏览器访问 \`ziso.cc\`。
2. **添加到主屏幕**：点击底部的“分享”图标，选择“添加到主屏幕”。

> **注意**：必须在 Safari 中操作，其他浏览器内核（如微信内）不支持 PWA 安装。
