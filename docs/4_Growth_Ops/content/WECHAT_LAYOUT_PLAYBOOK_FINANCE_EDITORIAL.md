# 公众号排版发布手册：财经杂志风格

适用范围：

- `docs/4_Growth_Ops/content/*`
- `docs/5_Support_Ops/content/*`
- 公众号首发或公众号同步发布内容

目标：

- 把公众号排版从“临发前手工微调”升级成“可复用、可审阅、可交接”的发布规范
- 让中文长文不再发闷、发挤、发散
- 统一成更像成熟财经杂志的阅读体验：整洁、大方、克制、清楚

## 一、先说结论

公众号排版真正要管理的，不是“有没有模板”，而是这 `4` 层：

1. 阅读参数是否统一
2. 信息层级是否稳定
3. 图片与留白是否形成节奏
4. 发布前是否有排版检查清单

如果这 `4` 层不固定，即使每篇都“重新美化”，最后读起来也还是会忽紧忽松、忽花忽素。

## 二、财经杂志风格的目标状态

我们要的不是：

- 花哨新媒体感
- 海报化排版
- 大色块卡片堆叠
- 每段都很短但信息密度很碎
- 用很多图标和分隔件强行做设计

我们要的是：

- 字体舒服，长时间读不累
- 留白明显，但不空
- 层级清楚，但不过度装饰
- 图片像 editorial 插图，不像活动海报
- 重点被温和强调，而不是大面积高亮

一句话定义：

`像一本移动端财经杂志，不像一张公众号宣传单。`

## 三、移动端阅读参数基线

结合中文手机阅读研究与公众号排版实践，默认采用下面这一组基线：

- 正文：`15px`
- 行距：`1.75 - 1.9`
- 段距：约 `1.0` 倍正文行距
- 每段建议：`2-4` 行
- 每段理想字数：`40-90` 个中文字符
- 小标题字号：`17-19px`
- 强调色数量：`1` 个主强调色 + 黑灰正文

说明：

- 研究显示，中文手机阅读中，字号与行距都会显著影响阅读时间、疲劳感和舒适度；较大的行距通常更舒适，但过大又会增加滚动成本，因此 `1.5F - 2F` 是更稳妥的区间。
- 关于段落留白，研究也支持“可分辨的段落块”优于挤在一起的文字块；段间距拉开后，阅读时间反而可能更短。
- 面向公众号场景，再结合移动端经验，正文用 `14-15px` 最稳，其中长篇财经解释文更建议走 `15px`。

## 四、版式风格令牌

建议把公众号版式固定成 `3` 套，而不是每篇重新设计。

### 1. `finance_editorial_v1`

适用：

- `TOFU / MOFU` 长文
- 认知型、方法论型、案例型文章

风格：

- 正文 `15px`
- 行距 `1.8`
- 小标题前后留白明显
- 强调色克制
- 图少而准
- 引导读者“连续读下去”，不是频繁停下来点组件

### 2. `support_clean_v1`

适用：

- `BOFU` 帮助文
- 产品机制解释
- FAQ / guide

风格：

- 正文 `15px`
- 行距 `1.75`
- 小标题更明确
- 列表更常用
- 截图与注释优先

### 3. `campaign_brief_v1`

适用：

- 短促活动
- 节点公告
- 快讯式发布

风格：

- 正文 `14-15px`
- 行距 `1.7`
- 节奏更快
- 可适当增加分隔组件
- 不拿来承载长篇深读

原则：

- 长文只允许用 `finance_editorial_v1`
- 帮助文优先 `support_clean_v1`
- 短文才允许更紧凑

## 五、正文结构规范

### 1. 开头

开头前两屏最重要，默认结构：

- `1` 段熟悉场景
- `1` 段冲突或误区
- `1` 段本文核心判断

要求：

- 不要一上来就放分隔图
- 不要先写空泛背景
- 不要连续大段铺垫

### 2. 小标题

财经杂志感的小标题，要像“章节锚点”，不是“活动海报角标”。

建议只用这 `3` 种形式之一：

- 纯文字粗体小标题
- 细横线 + 小标题
- 编号 + 小标题

不要混用：

- 彩色底块标题
- 图标标题
- 多种编号体系
- 每一节换一种装饰

### 3. 段落

中文在公众号里容易显挤，核心不是“拆成很多回车”，而是控制段落块大小。

建议：

- 一段只说一件事
- 单段尽量不超过 `4` 行
- 数据句、判断句、转折句可单独成段
- 不做首行缩进
- 长句后面主动断开，让呼吸感出来

### 4. 强调

强调只允许少量使用：

- 核心判断加粗
- 关键数字加粗
- 极少量使用品牌强调色

不要：

- 通篇多色
- 一段里多处加粗
- 把高亮当作段落结构

## 六、图片与留白节奏

财经杂志感不是“图多”，而是“图在该出现的时候出现”。

默认节奏：

- 封面图 `1` 张
- 正文优先复用封面或放 `1-2` 张辅助图
- 每 `3-5` 屏允许出现一次视觉停顿

图片职责：

- 封面：负责点击和气质定调
- 正文图：负责节奏和理解，不负责重复讲一遍全文
- 卡图：负责转发，不参与正文排版

默认视觉原则：

- 优先静物、符号、桌面、设备中心构图
- 默认不使用具体人物肖像
- 用物件关系表达含义，而不是靠人物表情讲故事

禁忌：

- 每一节都放图
- 图片尺寸和风格不统一
- 图片前后留白不一致
- 把正文图做成第二张封面
- 默认用“一个投资者坐在那里”的方式硬讲概念

## 七、颜色与气质

财经杂志风格建议采用“高对比但低噪音”策略。

推荐：

- 正文主色：深灰近黑
- 辅助色：中性灰
- 强调色：暗金 / 深红 / 深绿 三选一
- 大面积背景：白或极浅暖灰

避免：

- 亮蓝、亮紫、荧光色
- 红绿同时大量使用
- 大面积纯黑底
- 频繁渐变和发光效果

## 八、发布环节怎么把排版管理起来

建议把排版纳入当前内容系统，而不是交给小编临场发挥。

### 1. 在 frontmatter 里管理“版式档案”

为每篇待发公众号内容补：

- `wechat_layout.profile`
- `wechat_layout.density`
- `wechat_layout.body_font_size`
- `wechat_layout.line_spacing`
- `wechat_layout.paragraph_spacing`
- `wechat_layout.heading_style`
- `wechat_layout.accent_color`
- `wechat_layout.checklist_version`

这会让“今天为什么这样排”变成可追踪信息。

### 2. 建一个团队模板库

无论用公众号后台直接排，还是借助第三方编辑器，都不要每篇重新拼。

建议固定保存：

- `财经长文模板`
- `帮助说明模板`
- `快讯短稿模板`
- `数据图注模板`
- `引用 / 金句模板`

外部工具层面，当前主流公众号编辑器普遍把“模板复用、团队协作、版本历史、导出同步”作为团队能力的一部分；如果团队准备把排版流程产品化，优先看这几个维度，不要只看样式数量。

### 3. 发布前加一道排版检查清单

建议在公众号发布前，固定检查这 `10` 项：

1. 正文是否统一为 `15px` 左右
2. 行距是否在 `1.75 - 1.9`
3. 是否存在超过 `4` 行的大段
4. 小标题样式是否全文统一
5. 强调色是否只保留 `1` 个
6. 图片风格和宽度是否统一
7. 图片前后留白是否一致
8. 前两屏是否已经讲清冲突和主判断
9. 是否存在多余分割线、图标、卡片样式
10. 手机真机预览时是否仍然显得清爽

### 4. 审核时把“内容审核”和“版式审核”拆开

建议不要只审文案本身。

最少分成：

- 内容审核：观点、事实、口径、风险
- 版式审核：密度、留白、层级、图片节奏

否则团队很容易出现“文案过了，但版式仍然很挤”的情况。

## 九、推荐的团队执行顺序

1. 文案在 Markdown 中定稿
2. 根据文章类型指定 `wechat_layout.profile`
3. 使用对应模板进入排版
4. 按检查清单做版式审核
5. 真机预览
6. 再进入 `distribution.wechat.ready / scheduled`

也就是说：

`approved` 不是发文终点，公众号内容还需要经过一次 `layout-ready` 的发布检查。

## 十、结合外部信息后的实际建议

如果你们要追求“财经杂志效果”，我不建议从“找更花的编辑器模板”开始，而建议从下面这条路线开始：

1. 先固定 `finance_editorial_v1`
2. 把正文统一到 `15px + 1.8 行距`
3. 严格限制小标题和强调样式数量
4. 把正文图减少到 `1-2` 张，提升留白
5. 把版式字段写进 frontmatter
6. 在发布前增加排版检查清单

这条路线比“继续手工微调每一篇”更容易稳定出高级感。
