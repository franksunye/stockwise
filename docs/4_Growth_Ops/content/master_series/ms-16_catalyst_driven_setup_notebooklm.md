# 事件驱动型进攻结构｜NotebookLM 输入稿

## 方法身份

- 新信息触发的交易框架
- 预期被改变后的重新定价原型
- 催化、价格反应、持续性共同确认的进攻方式

## 关键事实

- `Stockbee` 长期把 `Episodic Pivots Breakouts` 列为核心学习主题
- 这条路线长期单列 `Episodic Pivots (EP)`
- 不是所有消息都算催化
- 重点是预期是否被改写
- 价格和成交量必须给出真实反应
- 持续性比当天热闹更重要
- 常见催化包括业绩超预期、指引上修、新产品、政策变化、管理层变化

## 关键术语

- `Catalyst = 催化`
- `Repricing = 重新定价`
- `Setup = 交易结构`

## 核心判断

- 事件驱动型进攻结构最重要的地方，不是追新闻，而是看懂哪种变化足以改变市场预期。
- 它最重要的，不是消息本身，而是重新定价。
- 真正好的机会，往往来自预期被改写且市场开始认真回应的时刻。
- 它和普通动量突破的差别，在于它更强调“变化为什么发生”。

## 生成硬约束

- 做成 `8` 页中文极简 PPT
- 每页只放 `1` 个核心信息点
- 每页文字尽量控制在 `20-60` 字
- 不要把一页做成小文章
- 重点放方法定义、催化逻辑、关键术语、重新定价、长期影响
- 适合小红书、公众号配图、信息图传播
- 强调留白、大字号、快速理解

## 8 页页序

1. 它是什么
2. 它为什么重要
3. 它真正抓的是什么变化
4. 催化 / 重新定价 / setup 是什么
5. 为什么不是所有消息都算机会
6. 它解决什么问题
7. 今天为什么还有这么多人讲它
8. 一句话总结

## 视觉线索

- 一条旧轨迹突然拐弯
- 新信息推动重新定价
- 冲击感、变化感、拐点感
- 强对比、低字量、重估拐点感
