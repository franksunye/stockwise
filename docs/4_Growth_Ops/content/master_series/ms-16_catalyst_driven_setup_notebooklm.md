# 催化剂驱动：它最重要的地方，不是追新闻，而是看懂哪种变化足以改变市场预期。

## 方法身份

- `Catalyst-Driven Setup = 事件驱动型进攻结构`
- 预期改写与重新定价模型
- 突发爆发型 Setup 母原型

## 关键事实

- 核心逻辑：重大新信息进入市场，瞬间改写了原本的估值或增长预期，引发价格剧烈调整（Repricing）。
- `Stockbee` (Pradeep Bonde) 路线最经典的子方法是 `Episodic Pivots (EP)`。
- `EP` 的事实定义特征：
  1. 强催化剂（如业绩大超预测、管理层重组、重大利好公告）。
  2. 价格强跳空或放量大涨。
  3. 伴随成交量异常放大（通常是 5-10 倍以上）。
- 催化剂分类：业绩超预期（Earnings Surprise）、订单/产品突破、宏观/行业拐点、企业重组等。

## 关键术语

- `Catalyst = 催化` (预期改写的导火索)
- `Repricing = 重新定价` (价值轴心的平移)
- `Episodic Pivot = 情报枢纽/EP` (最强的一类事件驱动机会)
- `Expectation Gap = 预期差` (盈利的空间来源)

## 核心判断

- 真正的催化不是热闹的新闻，而是足以逼市场重新算账的事实。
- 价格和成交量的强反应，是市场承认“预期已被改写”的第一证据。
- 动量往往在逻辑发生断裂、转向上方的那个瞬间爆发最猛。

## 生成硬约束

- 做成 `8` 页中文极简 PPT
- 每页只放 `1` 个核心信息点
- 每页文字尽量控制在 `20-60` 字
- 重点放催化定义、重新定价逻辑、EP 事实特征、执行规矩与长期影响
- 强调留白、大字号、快速理解

## 8 页页序

1. 他是什么：预期被改写的“发令枪”
2. 他到底牛在哪里：为什么重大变化总伴随着爆发
3. 重新定价：当市场不得不停下来重算一遍账
4. 催化的品相：业绩、指引、产品与环境
5. EP 的瞬间：最暴烈的一类事件驱动信号
6. 它解决什么问题：如何分清一日热闹与持续性变化
7. 今天的意义：为什么变化永远是交易最核心的引擎
8. 一句话总结：预期变了，价格自然要长出新的样子

## 视觉线索

- 旧轨迹被新力量拉动的瞬间
- 逻辑断裂并重组的视觉隐喻
- 突发感、力量感、转向感
- 专业金融社媒风格、大字留白、高识别度内容
