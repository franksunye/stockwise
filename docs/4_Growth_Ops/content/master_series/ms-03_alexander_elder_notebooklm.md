# 亚历山大·埃尔德：真正的高手，不是多看几张图，而是学会给市场“加滤网”。

## 人物身份

- 亚历山大·埃尔德 (Alexander Elder)
- 《以交易为生》作者
- `Triple Screen` 三重滤网提出者
- 交易心理、风险纪律、多周期分析大师

## 关键事实

- Wiley 资料写明《Trading for a Living》初版于 `1993` 年出版
- Wiley 在 `2014` 年出版《The New Trading for a Living》
- 《以交易为生》是中文交易读者最熟悉的经典著作之一
- `Triple Screen` 至今仍被反复引用
- 长期把交易心理、风险管理和技术分析放在同一体系里讲
- 核心贡献是把“成熟交易”讲成一套完整秩序

## 关键术语

- `Triple Screen = 三重滤网`
- `Trading for a Living = 以交易为生`
- `Multi-timeframe Analysis = 多周期分析`

## 核心判断

- 真正成熟的交易，不是只看一个买点，而是先看方向，再看节奏，再谈风险。
- 单个信号远远不够，方向、节奏、风险和执行必须一起成立。
- 真正难的，不是多会看一个指标，而是能不能把交易想完整。

## 生成硬约束

- 做成 `8` 页中文社媒型极简 PPT
- 每页只承载 `1` 个核心信息点
- 每页文字尽量控制在 `20-60` 字
- 不要把一页做成小文章
- 重点放心理医生背景、以交易为生、三重滤网体系、秩序感
- 适合小红书、公众号配图、信息图传播
- 强调高留白、心理医生般冷峻冷静的秩序感
