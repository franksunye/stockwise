# 多周期确认｜NotebookLM 输入稿

## 方法身份

- 大方向、中节奏、小触发的分工体系
- 不同时间尺度共同确认的执行框架
- 让周期之间不再打架的方法

## 关键事实

- Wiley 资料显示，埃尔德在 `1993` 年《Trading for a Living》中公开写出 `Triple Screen`
- Wiley 在 `2014` 年推出《The New Trading for a Living》
- 大周期定方向
- 中周期看节奏
- 小周期找触发
- 重点不是图更多，而是分工更清楚
- 这是很多成熟方法共享的原理，不只属于某一个经典名字

## 关键术语

- `Timeframe = 周期`
- `Confirmation = 确认`
- `Trigger = 触发`

## 核心判断

- 多周期确认最重要的地方，不是多看几张图，而是让方向、节奏和触发终于站到同一边。
- 它最重要的，不是复杂，而是秩序。
- 真正成熟的决策，不是所有信息一起喊，而是不同尺度各司其职。
- 它和 `Triple Screen` 的差别，在于前者更像经典体系，后者更像从经典体系里抽出的通用原理。

## 生成硬约束

- 做成 `8` 页中文极简 PPT
- 每页只放 `1` 个核心信息点
- 每页文字尽量控制在 `20-60` 字
- 不要把一页做成小文章
- 重点放方法定义、分工逻辑、关键术语、执行秩序、长期影响
- 适合小红书、公众号配图、信息图传播
- 强调留白、大字号、快速理解

## 8 页页序

1. 它是什么
2. 它为什么重要
3. 它真正解决什么冲突
4. 周期 / 确认 / 触发是什么
5. 大方向 / 中节奏 / 小触发如何分工
6. 它解决什么问题
7. 今天为什么还有这么多人讲它
8. 一句话总结

## 视觉线索

- 三层结构对齐
- 大中小周期分工
- 秩序感、层次感、对齐感
- 强对比、低字量、结构对齐感
