# 尼古拉斯·达瓦斯：交易的真谛，是看清股票正在哪层“箱子”里跳舞。

## 方法身份

- `Nicolas Darvas = 尼古拉斯·达瓦斯`
- 经典箱体理论 (Box Theory) 鼻祖
- 《我如何在股市赚了 200 万》作者

## 关键事实

- 建立“箱体理论”：核心在于将股价波动划分为不同的垂直区间。只有当价格向上冲破当前箱顶并站稳时，才标志着新一轮涨势的开启。
- 职业背景与独立思考：身为顶级社交舞者，他在全球巡演期间仅靠电报指令完成巨额交易。通过人为制造的“物理隔离”，他彻底屏蔽了当时华尔街的所有虚假内幕与噪音。
- 逻辑核心：股票不只是数字，而是有惯性的物体。我们要关注的是它是否向上跳进了更高一级的“舞池”（箱体），并利用跟踪止损来保护利润。

## 关键术语

- `Darvas Box = 达瓦斯箱体` (定义波动的上下界)
- `Breakout = 突破出头` (开启新舞程的唯一信号)
- `Ignore the Noise = 屏蔽噪音` (远离人群，只看价格)
- `Dancing in Boxes = 箱子里的舞蹈` (极其形象的趋势跟随描述)

## 核心判断

- 交易世界最震撼的正见，是发现绝大多数所谓的“内幕”其实都是亏损的毒药。
- 价格会说谎，但箱体边界是真实的博弈底线。别去猜主力在干什么，要看价格是不是已经跳到了天花板上面。
- 达瓦斯的价值，是证明了一个平凡人只要守住那套简单的“箱体规则”和“远离噪音的定力”，就能跑赢整个华尔街。
