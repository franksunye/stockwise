# 事件拐点（Episodic Pivot）｜NotebookLM 输入稿

## 方法身份

- `EP = Episodic Pivot = 事件拐点`
- 事件驱动动量方法
- 重大催化剂触发的强势拐点
- 价格、成交量、预期同时切换的爆发点

## 关键事实

- `Stockbee` 长期把 `Stockbee Episodic Pivots Breakouts` 列为核心学习主题
- 这条路线长期单列 `Episodic Pivots (EP)` 与 `EP Entry, Stops, Size and Exits`
- 重点不只是上涨，而是预期切换
- 必须有催化剂
- 必须有参与度
- 必须有强价格冲击
- 它不是泛泛的事件驱动，而是事件驱动爆发路线里最锋利的一种

## 关键术语

- `EP = Episodic Pivot = 事件拐点`
- `Catalyst = 催化剂`
- `Participation = 参与度`

## 核心判断

- EP 最值钱的，不是一根大阳线，而是市场突然开始用新逻辑看它。
- 真正值得追的，不是所有大涨，而是能改写市场预期的爆发。
- 它抓的不是热闹，而是定价逻辑真正换挡的瞬间。
- 它和普通动量突破的差别，在于它更强调强催化和预期切换。

## 生成硬约束

- 做成 `8` 页中文极简 PPT
- 每页只放 `1` 个核心信息点
- 每页文字尽量控制在 `20-60` 字
- 不要把一页做成小文章
- 重点放方法定义、催化剂、参与度、预期切换、长期影响
- 适合小红书、公众号配图、信息图传播
- 强调留白、大字号、快速理解

## 8 页页序

1. 它是什么
2. 它为什么厉害
3. 一根大阳线不等于 EP
4. `EP` 是什么
5. 催化剂 / 参与度为什么重要
6. 它解决什么问题
7. 今天为什么还有这么多人讲它
8. 一句话总结
