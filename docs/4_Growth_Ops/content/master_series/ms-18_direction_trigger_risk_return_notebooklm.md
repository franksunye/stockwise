# 先方向，后触发，先风控，后收益｜NotebookLM 输入稿

## 原则身份

- 方向优先于动作
- 风险优先于收益幻想
- 一整套决策顺序

## 关键事实

- 埃尔德在 `1993` 年公开写出的 `Triple Screen` 本身就是“先方向、再触发”的经典顺序
- `1983-1984` 海龟路线把规则和风险定义放在趋势利润之前
- 米勒维尼在 `2013` 年公开成书的 `SEPA` 先讲出手资格和风险边界
- 先方向
- 后触发
- 先风控
- 后收益
- 这不是一句漂亮口号，而是很多成熟方法共享的决策顺序
- 它真正反对的是“只看买点”的单点思维

## 关键术语

- `Direction = 方向`
- `Trigger = 触发`
- `Risk Control = 风控`
- `Reward = 收益`

## 核心判断

- 这条原则最重要的地方，不是口号，而是一整套决策顺序。
- 它最重要的，不是先想赚多少，而是先让交易不失序。
- 真正成熟的交易，先把方向、触发、风险、收益排成正确顺序。
- 它能成立，是因为很多经典方法最后都会回到同一套顺序：先看是否站得住，再看是否值得做。
