# DTR-R：交易不是一团乱麻，它是由四个拆得开、说得清的“核心零件”组成的。

## 方法身份

- `DTR-R = Direction, Trigger, Risk, Return`
- 交易决策的总纲章法
- 全系列方法论的底层零件图

## 关键事实

- 埃尔德在 `1993` 年公开写出的 `Triple Screen` 核心流程：先趋势（大方向），再触发（入场点）。
- 米勒维尼在 `2013` 年的 `SEPA` 体系：先筛资格与定死风险边界，再谈进攻盈利。
- `1983-1984` 海龟实验：将风险管理（N 位、Position Sizing）置于趋势追踪的具体利润之前。
- 结论事实：成熟的交易系统必然遵循“先定方向，后找触发，先定死风险，后谈收益”的逻辑顺序。

## 关键术语

- `Direction = 方向` (交易的舵，解决“干不干”的问题)
- `Trigger = 触发` (交易的门，解决“什么时候动”的问题)
- `Risk = 风险` (交易的底线，解决“错多少”的问题)
- `Return = 收益` (交易的果实，最后才考虑的结果)

## 核心判断

- DTR-R 最震撼的正见，是它揭示了交易的高手感，来自于极其严谨的决策顺序。
- 交易不是一个盲盒，而是由四个可拆解、可检修的零件组成的机器。
- 绝大多数失败，是因为把“最后才结的果（收益）”当成了“控制大局的舵（方向）”。
