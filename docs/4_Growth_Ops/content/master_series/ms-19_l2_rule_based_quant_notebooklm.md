# 什么是 L2 级规则量化｜NotebookLM 输入稿

## 概念身份

- 介于主观交易和黑箱量化之间的一层
- 把经验压成规则的中间层
- 强调可解释、可回测、可复核

## 关键事实

- `1983` 年海龟实验证明，公开规则可以被明确教给新人
- 埃尔德在 `1993` 年《Trading for a Living》里把 `Triple Screen` 写成清楚步骤
- 米勒维尼在 `2013` 年《Trade Like a Stock Market Wizard》里公开 `SEPA`
- 不否认经验
- 但要求经验被写成规则
- 规则要能回测、迭代、复核
- 重点不是神秘，而是可落地
- `L2` 不是官方统一分级，而是一种便于理解的分层叫法
- `Triple Screen`、海龟交易、`SEPA / VCP` 这类经典方法，其实都更接近这一层

## 关键术语

- `Rule-based = 规则化`
- `Explainable = 可解释`
- `Backtestable = 可回测`

## 核心判断

- L2 级规则量化最重要的地方，不是神秘，而是把经验压成可以复核的规则。
- 它最重要的，不是黑箱化，而是建立一层可解释的中间层。
- 真正现实的系统化路径，往往不是一步跳到黑箱，而是先把经验写成规则。
- 它适合放在这套系列里，因为很多经典方法最后都要经过这一层，才可能变成长期可复核的系统。
