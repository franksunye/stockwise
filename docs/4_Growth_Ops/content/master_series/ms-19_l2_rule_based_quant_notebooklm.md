# L2 级规则量化：交易高手的分水岭，是不敢不敢把手感变成标准动作。

## 方法身份

- `L2 Rule-based Quant = 规则量化中间层`
- 经验提纯规则
- 主观手感与黑箱机器之间的桥梁

## 关键事实

- 核心逻辑：不通过程序员写代码，而是通过交易员自己将模糊的“经验”翻译成可以被复核、回测、并交由他人执行的“标准动作”。
- 1983 年海龟交易实验证明了这一点的有效性：只要规则足够明确，即便是没有交易背景的新人也能执行复杂的趋势追踪逻辑。
- 这类方法包括：Elder 的 `Triple Screen`、海龟交易规则、Minervini 的 `VCP` 结构化标准。
- 关键特征：可解释、可回测、可复核。

## 关键术语

- `Experience Distillation = 经验提纯` (把手感里的水挤出去)
- `Rule-based = 规则化` (把算法写在纸上)
- `Empirical Algorithm = 经验算法` (人脑里的确定性逻辑)
- `Reviewability = 可复核性` (让外行也能替你监督)

## 核心判断

- 规则化量化最震撼的正见，是它证明了所谓的“神仙手感”通常只是还不清楚的算法；翻译出来，神仙就变成了手艺。
- 如果你没法把你的方法写在一张 A4 纸上让别人替你执行，那你就还不懂自己的系统。
- 真正的大路，是通往“确定性”的路，而不是通往“更复杂代码”的路。
