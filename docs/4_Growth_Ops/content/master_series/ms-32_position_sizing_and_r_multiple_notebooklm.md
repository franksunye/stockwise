# 仓位管理与 R 倍数：交易的真谛，是算清每一把下注的“风险单位”。

## 方法身份

- `Position Sizing = 仓位管理` (决定押注大小)
- `R-Multiple = R 倍数` (衡量收益效率的统一刻度)
- 风险管理与博弈论的核心组件

## 关键事实

- 交易的本质是筹码游戏：账户的长期表现不取决于选股的胜率，而取决于在错误时亏得少 (1R)，在正确时赢得多 (3R+)。
- 统一风险单位 (R)：将单次预设亏损定义为 1 个 R。这让所有的交易（无论买哪只票、本金多少）都能放在同一把“风险尺子”上比较。
- 规模决定生死：仓位大小才是控制风险的闸门。顶级大师先计算能输多少，再倒推该买多少股，绝不随手梭哈。

## 关键术语

- `R-Multiple = R 倍数` (结果除以初始风险得到的倍数)
- `Position Sizing = 仓位规模` (最核心的风险调节旋钮)
- `Risk Unit = 风险单位` (衡量博弈代价的唯一标准筒)
- `Survival First = 生存第一` (所有的计算都是为了不被踢出局)

## 核心判断

- 风险管理最震撼的正见，是发现金额结果往往带有欺骗性。唯有放回 R 倍数的维度，你才能看清自己是在靠实力赢球，还是靠重仓博运气。
- 止损只是第一道防线，仓位规模才是真正的保命符。如果你不知道这一把押了多少个 R，那你的复盘就还没入门。
- 章法的真谛，是永远先想“如果错了会怎样”。学会用 R 说话，剩下的就是守住那份不乱动筹码的节制。
