# 系统开发与期望值｜NotebookLM 输入稿

## 桥梁主题身份

- 系统开发核心桥梁
- `Expectancy / 期望值` 主题
- 从单次输赢回到长期统计的方法
- 纠正胜率迷信与样本幻觉的重要主题

## 关键事实

- 范·撒普路线长期把 `Expectancy / Expected Value` 当成系统评价语言
- 高胜率不一定比高盈亏比系统更好
- 真正价值在于纠正胜率迷信与样本幻觉
- 它帮助把系统评价从单次对错拉回长期正期望值

## 关键术语

- `Expected Value / Expectancy = 期望值`
- `Win Rate = 胜率`
- `System Development = 系统开发`

## 核心判断

- 系统开发与期望值最重要的地方，不是追求每次都对，而是先确认长期做下去到底值不值得。
- 真正值钱的，不是几个漂亮样本，而是长期下来是不是正期望值。
- 它最想反对的，是把单次输赢和胜率当成系统本质。
