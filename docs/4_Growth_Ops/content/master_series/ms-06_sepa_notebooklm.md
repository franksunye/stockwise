# SEPA：它最厉害的地方，不是教你找买点，而是教你如何拒绝平庸的机会。

## 方法身份

- `SEPA = Specific Entry Point Analysis = 特定入场点分析`
- 成长股趋势交易体系
- 严格出手资格审查
- 趋势、基本面、结构、风险统一方法

## 关键事实

- SEPA = Specific Entry Point Analysis (特定入场点分析)
- 米勒维尼 (Mark Minervini) 交易体系的母系统
- 核心逻辑：只有基本面、趋势、结构、风险四项同时过关，才产生“入场许可”
- 真正价值：不是教人多交易，而是把 90% 的平庸机会挡在门外

## 关键术语

- `SEPA = 特定入场点分析`
- `Base = 价格形态底部 / 平台`
- `VCP = 波动收缩形态 (Volatility Contraction Pattern)`
- `Pivot = 买入点 / 支点`

## 核心判断

- SEPA 最震撼的正见，不是“看到突破就跟”，而是教你如何用极其挑剔的章法，去拒绝那些不配出手的平庸。
- 真正的高胜率，不是靠猜得准，而是靠筛选得狠。
- SEPA 的本质是一层层漏斗，最终留下的只有极少数真正合格的成长股。

## 生成硬约束

- 做成 `8` 页中文极简 PPT
- 每页只放 `1` 个核心信息点
- 每页文字尽量控制在 `20-60` 字
- 不要把一页做成小文章
- 重点放核心逻辑、筛选纬度、拒绝平庸、入场章法与长期影响
- 适合小红书、公众号配图、信息图传播
- 强调留白、大字号、快速理解

## 8 页页序

1. 他是什么：米勒维尼引以为傲的秘密武器
2. 他到底牛在哪里：为什么 90% 的机会都不配出手
3. SEPA 的层层筛网：趋势、基本面、价格结构与风险
4. 什么是“特定入场点”：找到张口就咬的瞬间
5. 拒绝平庸：为什么守纪律比找买点更难
6. 它解决什么问题：如何从海量股票中定位真领导者
7. 今天 SEPA 对我们的启发是什么
8. 一句话总结：在对的时候，做最对的标的
