# SEPA：它最厉害的地方，不是教你看一个买点，而是把出手资格压得极其苛刻

## 一句话先讲明白

`SEPA` 最重要的价值，不是让你“找到突破点”，而是先决定：

**什么样的标的、什么样的趋势、什么样的结构，才配得上你出手。**

它的全称是 `Specific Entry Point Analysis`，中文可以理解成“特定入场点分析”。

很多人看到的是最后那个“点”，真正重要的其实是前面那一整套极其苛刻的筛选逻辑。

## 它是什么

如果只看中文交易社区最常见的理解，`SEPA` 大概可以被概括成三句话：

1. 成长股趋势交易体系
2. 严格的出手资格审查
3. 把趋势、基本面、结构和风险统一起来的方法

这三件事很关键，因为它们分别回答了三个普通读者最在意的问题：

1. 这是不是只看图形
2. 这是不是只讲一个买点
3. 这套方法到底靠什么提高胜率

`SEPA` 的特别之处，在于它不是鼓励你更快地冲进去，而是要求你先排除大量根本不配出手的机会。

## 它为什么会让很多人佩服


在大众视角下，SEPA 常被简化成“突破就买”。但如果你真的理解米勒维尼，你会发现 SEPA 的真章，不是那个入场瞬间，而是在那之前的每一层严苛筛选。

如果只讲最有代表性的硬特点，可以先记这几条：

1. `2013` 年出版的《Trade Like a Stock Market Wizard》公开把 `SEPA` 写成米勒维尼的标志性方法之一
2. 它强调二阶段趋势，不是在乱势里强行做交易
3. 它强调基本面加速，不是只看价格自己热闹
4. 它强调结构收缩和低风险入场，不是“先买了再说”

落到交易动作上，其实就是：

**SEPA 不在教你怎么多做交易，而是在教你怎么把大多数烂交易拒之门外。**

这也是为什么很多人会佩服它。因为真正难的，从来不是看见一条突破线，而是能不能在机会没成熟之前一直忍住。

## 术语卡：这篇里最重要的三个行话

读 `SEPA`，最常见也最容易被反复引用的，就是这几个词：

1. `SEPA`
   - 全称是 `Specific Entry Point Analysis`
   - 中文可写“特定入场点分析”
2. `Stage 2`
   - 中文常写“二阶段上涨趋势”
   - 指标的已经进入较健康的主升浪阶段
3. `Pivot`
   - 中文常写“枢轴点”
   - 指真正值得关注的关键突破位置

很多人只记住了术语，却忘了它们真正服务的目标：

**不是为了显得更专业，而是为了让出手条件更严格。**

## 它最重要的三个核心观点

### 1. 不是所有上涨都值得交易

`SEPA` 的第一道门槛，就是趋势筛选。

如果大结构不对，再漂亮的小结构也可能只是幻觉。

### 2. 好买点来自好结构，不来自情绪冲动

`SEPA` 真正看重的，不只是“涨起来了”，而是：

1. 回撤是否逐步收紧
2. 成交量是否逐步干净
3. 价格是否靠近关键枢轴点

这也是为什么它和 `VCP` 经常一起出现。

### 3. 真正好的机会，允许更近的否定点

`SEPA` 特别重视风险回报。

它希望你在一个很干净的结构附近出手，这样一旦错了，可以更快认错；一旦对了，盈亏比会更漂亮。

## 代表方法：趋势 + 基本面 + 结构 + 枢轴点

如果把 `SEPA` 压缩一下，最核心的就是四件事：

1. 趋势是否健康
2. 基本面是否加速
3. 结构是否收缩
4. 枢轴点是否明确

它为什么经典？

因为它把“找买点”这件事，变成了“先验证你有没有资格找买点”。

而且这套方法不是中文社区后加的简称。公开书籍资料直接把 `SEPA` 和米勒维尼的代表作连在一起，这就是它最硬的出处之一。

## 它和 `VCP`、`Trend Breakout` 的差别，到底在哪

很多人会把 `SEPA`、`VCP` 和普通趋势突破混在一起。

更稳的区分方式是：

1. `SEPA`
   - 是完整的出手资格体系
2. `VCP`
   - 是其中最有辨识度的结构语言之一
3. `Trend Breakout`
   - 是更抽象的母策略原型

也就是说，`SEPA` 不是单独一个形态，也不是只剩一个突破动作，而是一整套筛选秩序。

## 它解决了什么问题

`SEPA` 主要解决的是：

**如何在成长股强趋势里，找到一个更有纪律、也更有盈亏比优势的入场点。**

这对普通投资者最有价值的地方在于，它把“追涨”拆成了两件完全不同的事：

1. 情绪化追高
2. 纪律化突破入场

## 它不适合解决什么问题

这套方法并不适合：

1. 价值股长期估值研究
2. 高频和超短线博弈
3. 在弱趋势和乱震荡里强行做交易
4. 完全不愿止损的人

所以 `SEPA` 不该被理解成“见突破就买”的简单规则，更不该被神化成万能按钮。

## 今天为什么还有这么多人反复讲它

真正让 `SEPA` 留下来的，不是缩写本身，而是它把一个长期存在的难题讲得非常清楚：

**好机会很少，真正专业的人，首先是在过滤，而不是在忙着出手。**

这也是为什么到今天它仍然有生命力。因为它讲的不是某个时代的小技巧，而是“如何提高出手资格”这件事。

## 最后一句总结

如果要用一句话概括 `SEPA`，那不是“突破买入法”。

更准确地说：

**它是在提醒你，真正重要的，不是会找买点，而是知道什么样的机会才配得上你出手。**

## NotebookLM 交接要点

### 第 1 步：先整理一份“精选交接包”

不要直接把整篇文章原文扔给 NotebookLM。

先手动整理成一份短文档，再上传。建议文档内容只保留下面这些：

1. `方法身份卡`
   - 成长股趋势交易体系
   - 严格出手资格审查
   - 趋势、基本面、结构、风险统一方法
2. `关键术语卡`
   - `SEPA = Specific Entry Point Analysis`
   - `Stage 2 = 二阶段上涨趋势`
   - `Pivot = 枢轴点`
3. `一句话判断卡`
   - SEPA 最厉害的地方，不是教你看一个买点，而是把出手资格压得极其苛刻
4. `8 页页序卡`
   - 只写页标题，不写长段解释
5. `视觉线索卡`
   - 一层层筛网
   - 最终只留下极少数机会
   - 干净、克制、过滤感

### 第 2 步：新建 NotebookLM notebook

1. 为这篇单独建一个 notebook
2. 输出语言先设成 `中文（简体）`
3. 上传整理好的 `精选交接包`
4. 如果需要，再补 1 份原始 canonical 文稿做参考

### 第 3 步：先生成 PPT

先做 `Slide Deck`，不要先做音频，也不要先做信息图。

推荐设置：

1. 格式选 `Presenter Slides`
2. 长度选 `Short` 或 `Default`
3. 不要优先选 `Detailed Deck`

自定义提示词直接用这版：

```text
请基于我上传的资料，生成一份 8 页中文社媒型极简 PPT，采用 Presenter Slides 风格。每页只承载 1 个核心信息点，文字尽量控制在 20-60 字。突出方法定义、严格筛选、关键术语、核心纪律与长期影响。不要写成长篇讲义，不要把多条观点塞进同一页。整体风格适合小红书、公众号配图和信息图传播，强调视觉留白、信息识别和快速记忆。
```

### 第 4 步：用这 8 页结构检查 PPT

理想页序如下：

1. 它是什么
2. 它为什么厉害
3. 它真正筛选的是什么
4. `SEPA` 是什么
5. `Pivot / Stage 2` 为什么重要
6. 它解决什么问题
7. 今天为什么还有这么多人讲它
8. 一句话总结

### 第 5 步：如果第一版不对，优先重生成

1. 如果页序错了，重生成
2. 如果文字太多，重生成
3. 如果重点没落在“严格筛选”上，重生成
4. 只有结构基本对了，再做局部修订

### 第 6 步：再生成信息图

推荐设置：

1. 细节等级选 `Concise`
2. 方向选 `Square` 或 `Portrait`
3. 风格选 `Professional`

提示词直接用这版：

```text
请基于资料生成一张中文信息图，突出 3 个最关键的信息点：方法定义、严格筛选、关键术语。整体要简洁、留白、适合社交媒体快速传播，不要做成密集知识海报。
```

### 第 7 步：最后再生成音频

如果要做短音频，先试 `Audio Overview` 里的 `The Brief`。

提示词直接用这版：

```text
请生成一段简洁的中文音频概览，先讲 SEPA 为什么值得被记住，再讲它最有代表性的出手资格筛选逻辑。不要空泛聊天，不要展开太多细节，适合社交媒体快速收听。
```
