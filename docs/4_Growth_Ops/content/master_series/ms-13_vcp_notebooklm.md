# 波动收缩形态（VCP）｜NotebookLM 输入稿

## 方法身份

- `VCP = Volatility Contraction Pattern = 波动收缩形态`
- 强势股中的收缩结构
- 供给逐步衰减的观察语言
- 右侧低风险入场的重要辅助形态

## 关键事实

- 米勒维尼在 `2013` 年公开成书的 `SEPA` 路线里，用大量图例讲清“结构先变干净再找枢轴点”
- 常见特征是 `2-4` 轮越来越小的收缩
- 成交量会逐步变干
- 常与 `SEPA`、二阶段趋势、枢轴点一起出现
- 重点不是图形名字，而是卖压逐步变轻
- 它是很多右侧成长股经典路线反复回到的关键结构语言

## 关键术语

- `VCP = Volatility Contraction Pattern = 波动收缩形态`
- `Contraction = 收缩`
- `Volume Dry-up = 成交量萎缩`
- `Pivot = 枢轴点`

## 核心判断

- VCP 真正重要的，不是形态名字，而是卖压一层层变轻。
- 它最重要的，不是最后那根突破，而是突破前越来越安静的过程。
- 真正好的突破，很多时候来自供给已经先一步衰减。
- 它和 `SEPA` 的差别，在于它更像关键形态组件，而不是完整出手体系。
