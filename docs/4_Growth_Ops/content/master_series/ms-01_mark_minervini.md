# 马克·米勒维尼：他不是教你追涨，他是在教你只打最有把握的仗

## 一句话先讲明白

马克·米勒维尼（Mark Minervini）最重要的贡献，不是发明了一套“神秘图形”，而是把成长股趋势交易压缩成一套极端严格的筛选和入场纪律。

很多人看到的是 `VCP` 和突破；他真正反复强调的，其实是另一件事：

**只有在趋势、基本面、筹码结构和风险回报都同时对你有利的时候，才允许出手。**

## 他是谁

如果只看中文交易社区最常出现的标签，马克·米勒维尼大概会被概括成三句话：

1. 两届美国投资大赛冠军
2. 《股票魔法师》作者
3. `SEPA` 与 `VCP` 这条成长股趋势交易路线最有代表性的人物之一

这三件事很关键，因为它们分别回答了三个普通读者最在意的问题：

1. 他打赢过没有
2. 他有没有形成自己的系统
3. 他的影响力是不是只停留在一个小圈子里

米勒维尼之所以会被反复提起，不是因为他说话够狠，也不是因为图形名字够响，而是因为他同时占住了三样东西：

- 有成绩
- 有体系
- 有传播力

中文世界最常提到的作品之一，是《股票魔法师——纵横天下股市的奥秘》；英文原书名是 `Trade Like a Stock Market Wizard`。而 `VCP` 之所以传播得这么广，也和他的讲解与推广密切相关。

如果把他的方法缩成一句话，大概就是：

**不要在烂股票上练技术，不要在烂环境里赌运气，只做最干净、最强、最接近爆发点的那一小部分机会。**

## 他为什么会让很多人佩服

对于大多数初识者而言，一定会先问一句：

**这个人到底牛在哪里？**

米勒维尼最容易让人产生敬畏感的地方，不只是后来出了书、形成了体系，而是他先用成绩证明了自己确实配得上被听见。

如果只讲最能让普通用户立刻有感的那几条战绩，可以先记这组数字：

1. 官方资料明确写到，他在 `1997` 年赢得美国投资大赛，年度收益率达到 `155%`
2. 官方资料还写到，他在 `1995-2000` 这 6 年间，平均年回报约 `220%`，累计总回报约 `34,000%`
3. 官方官网现在仍直接把他称为“两届美国投资大赛冠军”
4. 中文交易社区常引用的另一条数据是：他在 `2021` 年再度夺冠，年度收益在 `334%` 左右

把这些数字翻成人话，其实就是：

**这不是一个只会讲形态的人，而是一个真的把账户做出过爆炸性增长的人。**

这类成绩为什么会让人印象深，不只是因为数字好看，而是因为它意味着：

1. 这不是纸上谈兵
2. 这不是只靠一两次碰运气的故事
3. 这是把筛选、等待、出手和止损长期做对后的结果

你可以不模仿他的风格，但很难否认一件事：

**能把这么挑剔、这么依赖纪律的方法长期执行下去，本身就已经很难。**

## 术语卡：这篇里最重要的两个行话

读米勒维尼，最常见也最容易被反复引用的，就是这两个词：

1. `SEPA`
   - 全称是 `Specific Entry Point Analysis`
   - 更稳妥的中文表达，可以写成“特定入场点分析”
   - 它不是单一指标，而是一整套围绕趋势、基本面、结构和入场点的交易框架
2. `VCP`
   - 全称是 `Volatility Contraction Pattern`
   - 中文圈常见写法有“波动收缩形态”和“价格波动收缩形态”
   - 它强调多轮收缩后，等待接近关键点的突破

很多人只记住了这些英文缩写，却忘了它们真正服务的目标：

**不是为了让交易听起来更高级，而是为了把出手标准压缩得更严格。**

## 他最重要的三个核心观点

### 1. 不是所有上涨都值得追

米勒维尼反复强调，只有处在健康上升趋势中的股票，才值得研究买点。

这背后的意思很简单：

- 弱趋势里的突破，失败率更高
- 逆势环境里的漂亮形态，往往也只是幻觉
- 真正的低风险入场，通常建立在更大级别已经走强的前提上

所以他不是“见突破就冲”，而是先过滤掉大量不该碰的标的。

### 2. 最值钱的不是看见机会，而是等到结构最紧的时候

`VCP` 常被翻译成“波动收缩形态”，但它真正想表达的，不只是图形美感，而是：

1. 回撤幅度越来越小
2. 成交越来越干
3. 抛压越来越少
4. 价格逐步收紧到关键点附近

这种结构之所以重要，不是因为它看起来漂亮，而是因为它意味着：

**如果这里真的向上突破，风险点可以设得很近，盈亏比会更好。**

### 3. 真正的高手，不靠扛单证明自己

米勒维尼很强调控制亏损。他的方法不建立在“大不了先买了再说”，而建立在“这笔交易一旦错了，我要尽快承认”。

所以这套体系的底层气质是：

- 等待
- 挑剔
- 进攻时坚决
- 错了时迅速退出

这也是为什么它对很多人看起来“难学”。

难的不是图形识别，而是你必须接受：

**大多数时候，最专业的动作其实是继续等。**

## 代表方法：SEPA 与 VCP

如果只记两个词，那就是：

1. `SEPA（Specific Entry Point Analysis，特定入场点分析）`
2. `VCP（Volatility Contraction Pattern，波动收缩形态）`

`SEPA` 更像完整方法框架，强调选股、趋势、基本面和入场点的统一。

`VCP` 更像其中最具代表性的结构语言，强调在多轮收缩后，等待接近枢轴点的突破时刻。

很多人只学到了“突破”两个字，却忽略了前面的筛选过程。真正决定质量的，往往不是最后那根突破线，而是突破之前你过滤掉了多少烂机会。

## 他解决了什么问题

米勒维尼主要解决的是：

**如何在强势股票里，寻找一个既顺势、又能把风险控制得很近的入场点。**

这对普通投资者最有价值的地方在于，它把“追涨”拆成了两件完全不同的事：

1. 情绪化追高
2. 纪律化突破入场

前者常常只是害怕错过，后者则要求你先确认趋势、确认结构、确认风险。

## 他不适合解决什么问题

这套方法并不适合：

1. 长期价值估值研究
2. 高频交易和日内抢反应
3. 在弱趋势、乱震荡里强行找买点
4. 完全不愿止损的人

所以米勒维尼不该被理解成“万能老师”，更不该被神化成一个万能按钮。

## 今天为什么还有这么多人反复讲他

真正让米勒维尼留下来的，不是某个单独名词，而是他把一类交易风格讲得足够清楚：

1. 只做强者
2. 只等好结构
3. 只在风险点足够近的时候出手
4. 一旦错了就尽快承认

这套东西为什么到今天仍然有人反复讨论？

因为它击中了一个长期存在的难题：

**大多数人并不是不知道什么叫突破，而是不知道该过滤掉多少“看起来像机会”的烂机会。**

米勒维尼最重要的地方，就是把“过滤”和“等待”本身，抬到了和“出手”一样高的位置。

## 最后一句总结

如果用一句话总结马克的交易哲学，那绝不是简单的“追高”。

他是在用几十年的战绩告诉我们：真正的高收益，从来不是靠频繁冒险换来的，而是极其有耐心地等出来的。

## NotebookLM 交接要点

### 第 1 步：先整理一份“精选交接包”

不要直接把整篇文章原文扔给 NotebookLM。

先手动整理成一份短文档，再上传。建议文档内容只保留下面这些：

1. `人物身份卡`
   - 两届美国投资大赛冠军
   - 《股票魔法师》作者
   - `SEPA / VCP` 路线代表人物
2. `战绩卡`
   - `1997` 年美国投资大赛冠军，年度收益 `155%`
   - `1995-2000` 六年平均年回报约 `220%`
   - 六年累计总回报约 `34,000%`
   - 中文社区常引用：`2021` 年再度夺冠，年度收益约 `334%`
3. `术语卡`
   - `SEPA = Specific Entry Point Analysis = 特定入场点分析`
   - `VCP = Volatility Contraction Pattern = 波动收缩形态`
4. `一句话判断卡`
   - 他真正教的不是追涨，而是极端挑剔的入场纪律
5. `8 页页序卡`
   - 只写页标题，不写长段解释
6. `视觉线索卡`
   - 干净的上升结构
   - 多轮收缩后的安静感
   - 临近枢轴点的等待感

### 第 2 步：新建 NotebookLM notebook

1. 为这篇单独建一个 notebook
2. 输出语言先设成 `中文（简体）`
3. 上传你整理好的 `精选交接包`
4. 如果需要，再补 1 份原始 canonical 文稿做参考

### 第 3 步：先生成 PPT，不要一开始做别的

先做 `Slide Deck`，不要先做音频，也不要先做信息图。

推荐设置：

1. 格式选 `Presenter Slides`
2. 长度选 `Short` 或 `Default`
3. 不要优先选 `Detailed Deck`

自定义提示词直接用这版：

```text
请基于我上传的资料，生成一份 8 页中文社媒型极简 PPT，采用 Presenter Slides 风格。每页只承载 1 个核心信息点，文字尽量控制在 20-60 字。突出人物战绩、代表体系、核心纪律与长期影响。不要写成长篇讲义，不要把多条观点塞进同一页。整体风格适合小红书、公众号配图和信息图传播，强调视觉留白、信息识别和快速记忆。
```

### 第 4 步：用这 8 页结构检查 PPT

理想页序如下：

1. 他是谁
2. 他到底牛在哪里
3. 他真正教的不是追涨
4. `SEPA` 是什么
5. `VCP` 为什么重要
6. 他解决什么问题
7. 今天为什么还有这么多人讲他
8. 一句话总结

检查标准：

1. 每页只有 `1` 个信息点
2. 每页文字尽量少
3. 不要出现长段讲义
4. 战绩页一定要有数字
5. 方法页一定要保留术语全称

### 第 5 步：如果第一版不对，优先重生成

不要急着逐页硬修。

正确做法：

1. 如果页序错了，重生成
2. 如果文字太多，重生成
3. 如果重点没落在战绩、体系和纪律上，重生成
4. 只有结构基本对了，再做局部修订

### 第 6 步：再生成信息图

PPT 方向确定后，再做 `Infographic`。

推荐设置：

1. 细节等级选 `Concise`
2. 方向选 `Square` 或 `Portrait`
3. 风格选 `Professional`

提示词直接用这版：

```text
请基于资料生成一张中文信息图，突出 3 个最关键的信息点：人物战绩、代表体系、核心方法。整体要简洁、留白、适合社交媒体快速传播，不要做成密集知识海报。
```

### 第 7 步：最后再生成音频

如果要做短音频，先试 `Audio Overview` 里的 `The Brief`。

提示词直接用这版：

```text
请生成一段简洁的中文音频概览，先讲人物最重要的战绩与地位，再讲他最有代表性的体系和普通人最该记住的一条纪律。不要空泛聊天，不要展开太多细节，适合社交媒体快速收听。
```

如果后面要做更完整的人物音频，再试 `Deep Dive`。

### 第 8 步：人工复核

NotebookLM 生成完以后，至少人工检查这几件事：

1. 战绩数字有没有丢
2. 术语全称有没有错
3. 中文表达是否顺
4. 有没有把一页塞成很多条信息
5. 有没有把人物稿写成空泛鸡汤

### 执行顺序

固定按这个顺序做：

1. 整理 `精选交接包`
2. 上传到 NotebookLM
3. 生成 `Presenter Slides`
4. 看结构，不对就重生成
5. 结构对了再修
6. 生成 `Infographic`
7. 生成 `Audio Overview`
