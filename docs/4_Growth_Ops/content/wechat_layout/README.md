# WeChat Layout Profiles

## finance_editorial_v1

文件：

- `finance_editorial_v1.css`

适用：

- 公众号长文
- 财经解释文
- 方法论文章
- 品牌气质要求克制、整洁、易读的内容

默认参数：

- 正文 `15px`
- 行距 `1.8`
- `H2` 带细分隔线
- 块引用浅暖灰底
- 图片上下留白偏大
- 表格、代码、链接均做弱化处理

使用建议：

1. 在 `mdnice` 或类似工具中导入该 CSS。
2. Markdown 写作时，单段尽量控制在 `2-4` 行。
3. 小标题优先使用 `##` 和 `###`，不要混入过多装饰组件。
4. 粘贴到微信公众号后台后，重点检查图片、引用块、表格和分隔线是否被微信重置。
5. 以手机预览效果为准，不要只看桌面编辑器。
