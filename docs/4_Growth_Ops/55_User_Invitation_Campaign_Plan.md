# 55. “知守AI”邀请活动策划案 (User Invitation Campaign Plan)

## 1. 核心目标 (Core Objectives)
*   **私域增长**: 利用“知守AI”现有的高价值功能进行社交裂变。
*   **反馈闭环**: 吸引种子用户体验并提供真实反馈（好评/吐槽/新需求）。
*   **转化实验**: 验证“5天试用 + 30天激活码奖励”机制的转化效率。

## 2. 核心卖点与钩子 (Core Value Props)
基于用户反馈，活动的“安利”钩子应聚焦于以下四个维度：
1.  **AI 分析师功课外包**: 
    - 每日个股复盘简报（DeepSeek 领衔，三位分析师模拟）。
    - 次日预测（观望、买入、卖出）及战术建议（图示、风险、自我反思）。
2.  **预测可追溯（绝对稳健）**: 
    - 内置“验证”机制，收盘自动复盘，统计胜率，对错留痕。
3.  **AI 投资黄历（情绪管理）**: 
    - 每日盘前“市场气象”与“宜/忌”，帮助投资者克服贪婪与恐惧。
4.  **极简体验**: 
    - 不用下载，链接即开（支持 PWA “添加到桌面”）。
    - 苹果设备支持实时买卖提示通知（15分钟行情同步）。

## 3. 活动机制与奖励体系 (Campaign Mechanism)
### 3.1 基础体验
*   **默认配置**: 注册即享 **5天** 专业版全功能体验（由于模型成本较高）。
*   **功能限制**: 
    - 免费用户：监控池 **3只** 股票。
    - 会员用户：监控池 **10只** 股票。

### 3.2 进阶奖励 (The Hook)
*   **奖励**: **30天专业版激活码**。当用户主动在公众号里面索取邀请码的时候，我们给到用户邀请链接 https://ziso.cc/v/ZISOAI 并告知用户使用提示。
*   **触发条件**: 
    1.  向官方/邀请人提供真实使用反馈。
    2.  反馈渠道：微信私聊或反馈群。

## 4. 推广素材规格 (Marketing Assets)
### 4.1 话术大图 (Copywriting Skeleton)
*   **Slogan**: “把耗时费力的股票功课外包给 AI。”
*   **关键话术**: “三位分析师干活”、“胜率对错留痕”、“绝对理性防脑热”。
*   **引导**: 提供测试链接 `https://ziso.cc/v/ZISOAI`，并提示 iOS 用户添加桌面。

### 4.2 视觉需求清单 (Visual Mockups)
- [ ] **预测效果图**: 展示 AI 预测买卖点的直观界面。
- [ ] **战术简报图**: 展示 DeepSeek 等模型的决策过程（反思、风险提示）。
- [ ] **大盘黄历图**: 展示极具直观感的“市场气象”视觉。
- [ ] **通知效果图**: 模拟苹果手机锁屏收到的买卖提示通知。

## 5. 执行路径与任务 (Tasks)
- [ ] **逻辑固化**: 确认邀请关联关系在数据库中的存储。
- [ ] **激活码系统**: 开发/配置 30 天激活码的生成与核销机制。
- [ ] **PWA 优化**: 确保“添加到桌面”引导逻辑在 iOS/Android 上的提示清晰。
- [ ] **通知稳定性**: 优化 15 分钟行情同步到 Push 通知的实时性。

---
> [!TIP]
> **运营细节**: 强调“等待 24 小时”模型预测逻辑，避免新用户因刚加自选没看到预测而产生挫败感。
