# 本地主链路影子测试最小样本集（2026-03-12）

## 1. 目的

在不高频轰本地 Gemini 的前提下，选择一组足够小、但能覆盖不同市场形态的样本，用于继续验证：

- `legacy`
- `B2_PROD_SAFE`

在本地主链路下的差异。

## 2. 选择原则

样本不追求多，而追求“形态有区分度”：

1. 破位防守型
2. 中性/无 setup 型
3. 可能带有观察意味的样本

## 3. 当前推荐最小样本集

### Case A: `300502 / 2026-03-12`

定位：

- 破位防守型
- Layer-1 = `RiskOff`

价值：

- 已完成首轮影子对照
- 是当前专项的主案例

### Case B: `00700 / 2026-03-12`

定位：

- 中性/无 setup 型
- Layer-1 = `NoSetup`

价值：

- 可验证 `NoSetup` 语义在本地主链路中是否仍被合理映射为防守型 `Side`
- 与 `RiskOff` 样本形成区分

### Case C: `601869 / 2026-03-12`

定位：

- 观察型
- Layer-1 = `Watch`

价值：

- 可验证 `Watch` 在 legacy 与 `B2_PROD_SAFE` 下的解释差异
- 对比 `RiskOff / NoSetup`，更接近“有关注价值但不应激进出手”的场景

## 4. 当前不建议加入的样本

暂不建议一开始就扩太多样本，尤其不建议：

- 一次性加入 10+ 个 case
- 引入需要额外清洗上下文的复杂异常标的
- 在本地 Gemini 容量不稳时做密集批量运行

## 5. 推荐执行顺序

建议按下面顺序跑：

1. `300502 / 2026-03-12`
2. `00700 / 2026-03-12`
3. `601869 / 2026-03-12`

原因：

- 先用主案例校准工具
- 再加 `NoSetup`
- 最后补 `Watch`
