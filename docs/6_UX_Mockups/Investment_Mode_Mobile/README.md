# Investment Mode Mobile Mockup

独立原型，不接入现有前后端代码。

## 预览

1. 直接双击打开 `index.html`
2. 或在项目根目录执行：

```powershell
cd docs/6_UX_Mockups/Investment_Mode_Mobile
python -m http.server 9037
```

然后访问 `http://localhost:9037`。

## 这版覆盖的核心 UX

- 首屏：不展示模式信息（零模式暴露）
- 模式抽屉：单选切换（只影响新预测）
- 绩效页：通用/监控池双轨 + 默认一图 + 深度两图
- 明细页：决策依据 + 模拟交易台账（明确非真实成交）
