# RFC: 2026 Q2 GTM 与产品策略微调 (Strategy Pivot)

**状态**: RFC (Draft)

## 1. 核心矛盾分析：为什么现在要调？ (The Core Dilemma)

### 1.1 系统能力与用户认知的极度不对称
- **后端现状**: 我们已经具备了 L2.5 级的 `择时 + 交易管理` 双引擎能力，可以实现从“发现信号”到“持仓管理”的完整闭环。
- **前端/市场现状**: 散户对“AI 炒股”的信任仍处于 L0 (怀疑/娱乐) 到 L1 (指标工具) 之间。我们尚未证明用户愿意为了“AI 解释逻辑”这一 v1 核心特性长期付费。
- **风险**: 如果我们在 GTM 中强行推广全闭环（v2），会让用户感到“认知过载”。

### 1.2 验证真空期 (Validation Gap)
- 我们默认了：信号准 + 解释顺 -> 用户会买单。
- 但现状是：我们还没有一个爆款案例，能够清晰证明“是因为看了 AI 的逻辑解释，用户才避免了大亏或抓住了大涨”。

## 2. GTM 内容策略调整：回归“逻辑发现” (Content Strategy)

我们需要从“教用户做交易（v2）”全面退回到“展示 AI 解释逻辑的魅力（v1）”。现有的内容矩阵需要进行一次体感层面的“降维”与“聚焦”。

### 2.1 三大内容板块的 v2 -> v1 映射

| 板块 | v2 叙事 (现存/重) | v1 叙事 (微调/轻) | 调整重点 |
| :--- | :--- | :--- | :--- |
| **101 学院** | 侧重：风险管理、止损艺术、仓位数学。 | 侧重：AI 识别逻辑、信号有效性、共识解构。 | 将“纪律说教”改为“逻辑解密”。从教用户“如何活下去”改为帮用户“看清规律”。 |
| **大师系列** | 侧重：完整的交易系统、生存哲学、资金管理。 | 侧重：大师的“眼光”、入场逻辑的结构化。 | 把大师看作 AI 的“逻辑算法原型”。不讲复杂的仓位公式，只讲大师如何“过滤噪音”。 |
| **Blitz Hub** | 侧重：通过管理引擎截断亏损、保住利润的绩效。 | 侧重：AI 信号的实时捕获、逻辑的快速兑现。 | 增加“逻辑复核 (Logic Audit)”模块，证明 AI 逻辑的先见之明，而非管理之功。 |

### 2.2 具体板块的调整细节

#### A. 101 学院：从“生存教练”转向“逻辑外挂”
- **存量清理**：对于《101-52: 止损的艺术》、《101-54: 仓位管理》这类纯管理文章，在 GTM 传播时进行低频处理或将其作为“Pro 用户进阶手册”。
- **增量策略**：新增《AI 为什么能看懂市场？》、《VCP 结构的 AI 底层拆解》、《逻辑共振：AI Council 的投票真相》等文章。
- **口语化表达**：从“你要守纪律”变成“AI 已经帮你算清了逻辑”。

#### B. 大师系列：从“系统传承”转向“逻辑模型”
- **米勒维尼 (ms-01)**：不讲他的仓位公式。只讲他如何识别“VCP 形态末端的极限静默”——这就是 AI 扫描器的“灵魂”。
- **埃尔德 (ms-03)**：不讲他的三重滤网组合管理。只讲他标志性的“多周期共振过滤器”——这就是 AI Council（顾问团）多视角投票的逻辑来源。
- **叙事锚点**：AI 是大师经验的“数字化直觉”。

#### C. Blitz Hub (实战案列)：从“绩效证明”转向“逻辑验证”
- **重点场景**：优先选择“信号发出 -> 逻辑解释 -> 24小时内行情兑现”的高爽点案例。
- **固定动作**：【逻辑复核】。要在复盘中明确展示信号发出时 AI 给出的原始逻辑话术，证明逻辑的确定性。

### 2.3 核心口径更新
- **不卖**: “跟我买，AI 帮你管仓位。” (太沉重，像老师)
- **主卖**: “看懂它，AI 帮你拆解爆发前的极限静默逻辑。” (够轻量，像外挂)

## 3. 产品策略调整：叙事收回，能力下沉 (Product Strategy)

产品侧应配合 GTM，从“功能堆砌”转向“信任经营”。

### 3.1 激活并显性化“验证闭环” (Surfacing Validation)
*   **现状审计**: 底层数据模型 (`AIPrediction`) 已实装 `validation_status` 和 `max_perf_in_window` 等 T+3 验证字段，但目前 `AICouncil` 界面并未将其显性化。
*   **策略建议**:
    *   **历史复核勋章**: 在历史信号卡片（Time Machine 模式）中，直接在 AI Council 卡片右上角增加验证结果（如：`T+3 峰值 +5.2% ✅`）。
    *   **信任背书**: 将“验证状态”作为 v1 解释逻辑的一部分，证明 AI 不是在乱猜，而是有据可查的逻辑兑现。

### 3.2 动态能见度管理：逻辑研判 (Actionable Insights) 核心化
*   **功能合并**: 废弃原有的“择时 (Timing)”与“决议 (Council)”双标签，在 UI 上统一为 **【逻辑研判 (Actionable Insights)】** 标签。
*   **价值逻辑**: 让用户第一眼消费的是“研判结论”，而不是复杂的“专家投票过程”。
*   **Contextual Trigger**: 在【逻辑研判】页面末尾提供“开启跟进 (Start Tracking)”按钮。点击后方激活被隐藏的 v2【交易管理】标签，实现从“消费逻辑”到“管理执行”的自然转化。

### 3.3 强化“研判详情”的信任梯度
*   **简化决策流**: 将原有的 Council 专家博弈下沉为后台逻辑，在前端体现为不同深度的“研判依据 (Rationale)”：
    *   **Free**: 展现极简研判摘要。
    *   **Go**: 展现 AI 完整的 **思维链 (Thought Chain)**。
    *   **Plus**: 展示由双顶级模型达成的 **专家共识 (Concensus Audit)** 与关键分歧。
*   **目的**: 确保 v1 阶段的每一个等级都能提供可见的、逐级递增的“逻辑透明度”，而非仅仅是信号的堆砌。

### 3.4 内部迭代架构与智能分级 (v1 / v2 / v3)

我们通过 v1/v2/v3 三个内部大阶段，将产品能力按照“决策深度”进行五级命名，建立清晰的升档路径：

*   **v1.0 (推理逻辑阶段)**: 核心目标是验证“AI 推理逻辑”的溢价能力。
    *   **Free**: 混元 Lite。自选 3 席。建立 UI 闭环体验。
    *   **Go**: DeepSeek 深度版。自选 10 席。主打“深度解析价值”。
    *   **Plus**: 双高级 LLM 共识。自选 10 席。
*   **v2 (管理执行阶段)**: 即 **Pro (专业版)**。
*   **v3 (优化终局阶段)**: 即 **Alpha (终极层)**。核心目标是交付“超额收益（Alpha）”。算力独占，提供择时与交易管理的极致优化。

### 3.5 全球化与多市场扩张 (Global Logic Expansion)

为最大化 AI 在跨语言、跨市场维度的“逻辑通用性”，我们在 v1 阶段同步开启全球化路线：

*   **多语言推理 (Reasoning i18n)**:
    *   **UI 汉化/英文化**: 启用 `app/[locale]` 架构，完成全量 UI 字符串的英文映射。
    *   **逻辑生成 i18n**: 基于用户 `locale` 偏好，AI 逻辑报告自动生成英文/中文推理链。利用 Gemini/DS 的原生多语言能力，实现“逻辑解释权”的无国界触达。
*   **市场覆盖范围 (Market Scope)**:
    *   **首批支持**: A 股、港股 (HKEX)、美股 (Nasdaq/NYSE)。
    *   **数据驱动**: 接入全球行情 `yfinance` 扩展，将美股明星标的纳入 ETL 高频分析排期。
*   **海外定价对标**:
    *   **Go ($4.99)** / **Plus ($9.99)** / **Pro ($29.99)**。利用低客单价优势，作为“逻辑增强插件”切入海外 Reddit/Discord 投资社区。

2. 在 ms-01 等 Growth 文档中，是否需要对“R倍数”等过深的量化词汇进行“二级折叠”处理？

### 5.2 商业化与权限 (Monetization)
3. **模型路由成本**: 后端 ETL 如何根据用户群体的 Tier 分布，最优化地派发 AI 任务（如：只有高级用户关注时才启动双 LLM 分析）？
4. **模型变现验证**: 用户是否真的愿意为了“更聪明的 AI 逻辑（DS/Gemini）”支付溢价，而非仅仅为了“更多自选位”？

### 5.3 治理与效率 (Governance & Efficiency)
5. **逻辑打脸处理**: 当 AI 的理由非常充分但结果反转时，UI 上如何通过“回审话术”维持用户对系统逻辑的底层信心？
6. **自动化效率**: 既然已有 `validation_data` 数据池，我们是否可以建立一个脚本，每周自动筛选最佳案例并填充 Blitz Hub 模板？
