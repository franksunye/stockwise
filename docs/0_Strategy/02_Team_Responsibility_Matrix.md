## 核心原则

- **双层解耦与流水线机制**：废弃原有的“平行独立研判”，重构为**先决触发与后置定性**的工业级流水线。
- **程矩（量化规则）升格为 Layer-1 先决触发器（Trigger）**：拥有行情的“开火权”与“一票否决权”。负责纯数学、无情感的异动捕捉（放量突破、破位止损）。
- **顾深、林序（AI 推理）降维为 Layer-2 战术参谋（Narrative）**：在程矩划定方向后介入，免除其“猜方向”的对齐负担。全盘接受量化红绿灯，结合诺岚的情报上下文，输出高专业度的战术解释（为什么破位？逻辑支撑是什么？具体仓位如何管理？）。
- 团队保持精简，不扩编；通过兼任机制覆盖运行与数据职责。

## On-call 与升级链（v1）

| 级别 | 触发条件                               | 首响人 | 升级路径                               | 对外口径  |
| ---- | -------------------------------------- | ------ | -------------------------------------- | --------- |
| P1   | 核心任务中断、无预测产出、全局通知故障 | 程矩   | 程矩 -> 维尔 -> 安德烈·谷 -> 弗兰克·孙 | 弗兰克·孙 |
| P2   | 局部数据异常、延迟、单模块不可用       | 维尔   | 维尔 -> 程矩 -> 安德烈·谷              | 诺岚      |
| P3   | 文案问题、体验瑕疵、低风险缺陷         | 诺岚   | 诺岚 -> 相关主责成员 -> 弗兰克·孙      | 诺岚      |

执行规则：
- 任一 P1 在 10 分钟内必须进入升级链。
- 任一事件在 24 小时内产出复盘记录（owner、根因、修复、预防）。
- 周会固定审阅 SLA/SLO 达成率与复发问题。
