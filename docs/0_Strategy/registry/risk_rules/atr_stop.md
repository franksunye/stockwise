# ATR Stop

## 一句话

根据波动率动态设置止损，而不是使用完全固定的百分比。

## 对 StockWise 的意义

这是一个很适合被工程化的风险规则。

它可以帮助：

1. 减少固定止损过硬或过松的问题
2. 让不同波动率标的的风控更一致

## 当前建议

- 作为风险规则候选优先研究
- 优先在研究线比较：
  - 固定止损
  - ATR 止损
