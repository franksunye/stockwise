# StockWise Method Registry

这是 StockWise 的最小化 Method Registry 起点。

当前目标不是做复杂系统，而是先把外部方法输入沉淀成结构化卡片，避免后续继续靠口头讨论。

## 目录

- `masters/`
  - 大师 / 思想源
- `methodologies/`
  - 完整方法体系
- `archetypes/`
  - 母策略原型
- `components/`
  - 可组合规则组件
- `risk_rules/`
  - 风控规则

## 当前约定

每张卡都尽量回答这几个问题：

1. 它是什么
2. 它属于哪一层
3. 它适合进入哪里
4. 当前状态是什么
5. StockWise 应该如何吸收

## 当前状态字段建议

- `parked`
- `researching`
- `baseline`
- `shadow`
- `candidate`
- `adopted`
- `rejected`

## 重要原则

1. 人物不直接等于产品模式
2. 方法不直接等于用户语义
3. 大多数外部输入，先进入研究线或解释层
4. 前台仍然统一回到：
   - 稳健 / 平衡 / 进取 / 仅观察
   - 建议进场 / 建议观察 / 建议防守 / 暂无信号
