## 0. 原则

- 先把模式做靠谱。

- 最后才放大增长实验。

### 已完成的基线

- **引擎基线已完成**
  - Layer-1 四状态体系已收口。
  - Spec 47 后端闭环已落地：`prediction -> decision -> ledger -> snapshot`。
- **B1 已完成**
  - 投资模式入口已固定在个人中心。
  - 个人中心已完成“一级入口 + 二级详情页”。
  - Free / Pro 边界、双轨表现首屏、基础性能补强已落地。
- **基础可靠性已达标**
  - 零闪烁秒开保持。
  - 可观测性看板已上线。

### 当前真正所处位置

- **当前主任务不是“继续做 B1”**
  - B1 已经上线到 `main`。
- **当前主任务是 B1.5**
  - 把模式做得更可信。
  - 把产品体验做得更完整、更一致。
- **增长实验还不应该前置**
  - 在模式可信度和产品完成度没过关前，增长只会放大噪音。

## 2. 当前里程碑

### M1 引擎可信度

- 状态：`进行中`
- 目标：让 Layer-1 / Layer-2 的裁决与解释形成稳定、可审计、可回放的可信系统。
- 当前重点：
  - 启动 A2，收口解释层。
  - 建立“解释与裁决冲突率”抽检与阈值。

### M2 模式产品完成度

- 状态：`进行中`
- 目标：让投资模式成为一个普通用户能理解、愿意使用、不会困惑的产品能力。
- 当前重点：
  - 继续打磨个人中心投资模式二级页。
  - 补齐 Dashboard / 投研决议 / 监控池 / 个人中心之间的语义一致性。
  - 收口“模式是什么、为什么切换、切换后会发生什么”的表达。

### M3 产品体验与可靠性

- 状态：`进行中`
- 目标：确保模式体验在性能、信息结构、交互节奏上达到可放大的标准。
- 当前重点：
  - 推进 SWR 统一。
  - 保持零闪烁秒开，不因模式功能回退。
  - 继续压缩模式页首屏等待与体验噪音。

### M4 增长实验

- 状态：`未开始`
- 前置条件：
  - 模式可信度达标。
  - 产品体验完成度达标。
- 启动后才做：
  - 模式入口触达实验。
  - 升级文案实验。
  - 默认模式引导实验。

## 3. 接下来 30 天

1. **优先完成模式产品打磨**
   - 先把模式做靠谱，把产品体验做优秀。
   - 这是当前最高优先级。
   - 执行计划：
   - 模式可信度收口：统一每个模式的名称、风格、风险带、一句话价值；明确“只影响后续新结论，不改历史记录”；校对 Free / Pro 边界。
   - 前端体验打磨：继续优化个人中心二级页的信息节奏、卡片层级、标题文案、状态提示，去掉工程感和后台感表达。
   - 跨页面语义一致性：统一个人中心、Dashboard、投研决议、监控池四处的模式术语与展示逻辑，避免心智断裂。
   - 性能与稳定性：保持懒加载、缓存、聚合接口方案，补齐切换、刷新、错误态、空状态、弱网场景的 focused QA。
   - 阶段验收：
   - 用户能稳定理解“模式是什么、为什么切换、切换后会发生什么”。
   - 个人中心模式页达到完整产品页标准，不像首页卡片搬移。
   - 模式体验在语义一致性、性能和稳定性上达到可放大标准，再进入增长实验。
   - B1.5 验收清单：
   - Free 用户：
     - 个人中心首页只看到“投资模式”一级入口，不在首页直接展开模式内容。
     - 进入二级页后，默认看到平衡模式与通用表现，不出现可切换的 Pro-only 误导。
     - 升级提示表达为权益增量，不是系统规则说明。
   - Pro 用户：
     - 进入模式页后，能直观看到当前模式、可切换模式、通用表现、监控池表现。
     - 切换模式后，提示语明确说明“只影响后续新结论，不改历史记录”。
     - 页面首屏不出现明显等待感，缓存与聚合接口生效。
   - 跨页面语义：
     - Dashboard 主结论只保留四语义：建议进场 / 建议观察 / 建议防守 / 建议空仓。
     - Historical Card、Tactical Brief、AI Council 只能解释主结论，不能再形成第二套判断语言。
     - 页面中不再暴露 `Layer-1`、内部规则名、工程式实现说明。
   - 状态面：
     - loading、empty、error、upgrade gate 都使用用户视角文案。
     - 弱网、空数据、切换失败时，页面保持稳定，不出现结构跳变或工程味错误信息。
   - 体验标准：
     - 个人中心二级页在布局、节奏、层级上是完整产品页，不是一级卡片搬家。
     - 模式、表现、决议、简报之间没有明显语义断裂。
