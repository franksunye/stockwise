## 0. 战略锚点（不随迭代摇摆）

- 产品定位：StockWise 是普通投资者的“AI 纪律合伙人”，不是高频交易终端。
- 核心价值：卖“可执行结论 + 行为修正”，不是卖“信息噪音”或“黑盒神谕”。
- 主路线：`Layer-1(量化裁决)` + `Layer-2(AI解释与计划)` 双层解耦。
- 商业策略：木马策略（表层寻宝获客，深层纪律留存），Q2 聚焦行为修正闭环。
- 执行顺序：先把模式做靠谱，再把产品体验做优秀，最后才放大增长实验。

## 3. 2026 Q2 专项（Project Echo）拆解

**代号**: `Project Echo`  
**目标**: 从“被动预测器”升级为“行为修正合伙人（交易界 WHOOP / Noom）”。

### E1 持仓审计魔镜（Portfolio Coach MVP）

- 交付：
  - `UserPortfolio` 安全存储层。
  - 持仓成本锚定与偏差审计。
  - 可执行风控建议（不提供收益承诺）。
- 验收：
  - 用户可看到“计划 vs 当前行为”的偏差解释。
  - 建议文案与四语义一致，不引入新术语漂移。

### E2 冲动防护（Impulse Guard MVP）

- 交付：
  - 盘中 60s 冷静机制。
  - `RiskOff` 触发的强提醒与解释卡。
- 验收：
  - 用户可被阻断并获得可理解理由。
  - 阻断功能对核心路径性能影响可控。

## 5. 发布规范与变更纪律

- **Major (X.0.0)**：商业逻辑重写或核心交互范式迁移。
- **Minor (0.X.0)**：里程碑子能力上线（含可验收证据）。
- **Patch (0.0.X)**：缺陷修复与兼容性修正。
- **文档纪律**：
  - 每周更新一次里程碑状态（含日期与证据）。
  - 每周复盘必须附带 observability gate（来自 `acceptance_weekly` 与 `/admin/observability`）。
  - 状态字段仅使用：`未开始 / 进行中 / 已完成 / 风险中`。
