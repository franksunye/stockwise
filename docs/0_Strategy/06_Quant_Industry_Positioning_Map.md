## 1. 先给总判断

### 1.1 最重要的结论

量化不是单一学科，也不是单一玩法。

它至少同时包含四层东西：

1. 研究什么信号
2. 如何验证这些信号不是幻觉
3. 如何把信号变成真实可执行的交易或组合
4. 如何把这一切变成能长期运行的产品或资金系统

很多团队只做了第 1 层，就自称在做量化。

真正成熟的量化体系，至少要把第 1、2、3 层连起来；顶级机构则把第 4 层也做成了系统工业。

### 1.2 ZISO 的当前位置

ZISO 当前不属于 HFT，也不属于机构级多因子组合平台。

它最准确的定位是：

**面向普通投资者的、可解释的、规则化的、产品导向的 L2 级量化系统。**

更具体地说：

1. 它不是“找市场最强 alpha”的机器
2. 它也不是简单指标提示器
3. 它是在做一套“规则研究 -> 参数治理 -> 模式产品化 -> 生产观测”的闭环

### 1.3 最合理的前进方向

ZISO 不该直接跳去 L4，也不该假装自己已经在 L3。

最合理的路线是：

**先把 L2 做扎实，再进化到 L2.5。**

这里的 `L2.5` 指：

1. 仍然坚持可解释规则与面向 C 端的动作语义
2. 但开始补齐 benchmark、风险归因、组合视角、正式样本外纪律、研究审计
3. 让系统从“规则研究工具”升级为“可信的规则投资产品底座”

## 2. 行业地图：量化到底在玩什么游戏

## 2.1 先看全图：量化金字塔

如果先从局部指标和技术细节入手，很容易迷路。

理解量化，最好的起点不是某个策略，而是先看整张行业地图。

最适合 ZISO 的宏观视角，是先看一座金字塔：

### L0 直觉驱动

特征：

1. 主要靠消息、感觉、K 线直觉
2. 没有稳定规则
3. 没有严谨验证

价值：

- 快，但不可复现

问题：

- 极度依赖个人状态

### L1 工具驱动型

特征：

1. 使用指标、扫描器、条件预警
2. 有规则碎片，但缺少完整研究治理
3. 往往只解决“看见了什么”，没解决“证据够不够”

代表：

- 各类指标插件、选股器、简单量化脚本

### L2 规则化量化研究

特征：

1. 有明确规则
2. 有历史回测
3. 有参数选择
4. 开始考虑样本外、多窗口、成本与上线治理

代表问题：

1. 这个规则是否稳定？
2. 这个规则是否真的可成交？
3. 这个规则是否值得进入产品或交易链？

**ZISO 当前主要位于这里。**

> **战术延伸阅读：我们的 L2 “兵器库”到底装了什么？**

### L3 系统化组合投资

特征：

1. 不再只关心单票规则
2. 开始关心组合权重、风险预算、容量、行业暴露、Beta 暴露
3. 用 benchmark、risk attribution、portfolio construction 统一研究语言

代表问题：

1. 超额收益来自哪里？
2. 风险承担是否值得？
3. 多个信号如何在组合层协同？

### L4 极硬量化

特征：

1. 速度、数据、基础设施、人才密度高度集中
2. 常见于 HFT、做市、统计套利、另类数据博弈
3. 竞争壁垒主要来自“物理世界”和组织工业能力

这不是 ZISO 应该进入的战场。

## 2.2 再看细节：行业不是一条线，而是四个维度

金字塔解决的是“成熟度层级”问题。

但如果只按“层级高低”理解量化，还是会误判方向。

更好的理解方式，是再把行业拆成四个维度：

### A. 时间维度

1. 毫秒到秒：HFT、做市、微观结构套利
2. 日内到数日：短周期统计套利、事件驱动
3. 数日到数周：趋势跟随、突破、波段
4. 数周到数月：因子轮动、组合配置
5. 数月到多年：资产配置、养老金、风险预算

### B. 边际优势来源

1. 速度优势
2. 数据优势
3. 模型优势
4. 执行优势
5. 组合构造优势
6. 产品表达与用户行为优势

### C. 输出对象

1. 单票信号
2. 单票交易规则
3. 股票池排序
4. 组合权重
5. 资金配置方案
6. 用户动作建议

### D. 组织形态

1. 个人研究脚本
2. 零售量化平台
3. 小型研究团队
4. 机构级系统化投资平台
5. 面向终端用户的量化产品

ZISO 当前最特殊的地方，不在于“比别人更量化”，而在于它落在：

**L2 规则量化 + C 端决策产品** 这两个坐标的交叉点。

## 2.3 从机构视角看，量化真正由什么构成

从全球主流系统化投资框架看，成熟量化一般包含五层：

1. **Signal Research**
   - 寻找可重复的收益信号
2. **Research Validation**
   - 控制过拟合、未来函数、样本污染
3. **Reality Modeling**
   - 成本、滑点、容量、成交约束
4. **Portfolio Construction**
   - 组合权重、风险预算、相关性、暴露控制
5. **Production Governance**
   - 发布、灰度、监控、审计、回滚

机构真正强的地方，通常不是“某个公式更神”，而是这五层都做成了系统。

这也是为什么：

1. 顶级机构不等于“会回测”
2. 顶级机构等于“把研究、执行、组合、治理做成一个工业闭环”

## 3. 行业地图里的三种主路径

## 3.1 路径一：硬核 alpha 工厂

目标：

- 找到更强的超额收益来源

核心投入：

1. 海量数据
2. 高性能研究基础设施
3. 更复杂模型
4. 组合优化与执行工程

适合谁：

- 对冲基金、量化私募、系统化资管

风险：

1. 极度烧钱
2. 极度依赖组织密度
3. 容易偏离终端用户真实需求

**这不是 ZISO 的主路径。**

## 3.2 路径二：规则化投资产品

目标：

- 把复杂市场判断压缩成稳健、可解释、可执行的规则产品

核心投入：

1. 规则研究
2. 样本外纪律
3. 风险与成本建模
4. 用户语义翻译
5. 产品闭环与长期观测

适合谁：

- 面向散户、顾问、内容产品、决策工具的团队

**这是 ZISO 的主路径。**

## 3.3 路径三：研究平台 / 基础设施平台

目标：

- 服务其他研究者或交易员去做量化

核心投入：

1. 数据平台
2. 回测框架
3. 优化框架
4. 实盘与模拟交易连接

代表气质：

- QuantConnect、Backtrader、Freqtrade 这类路线

这类平台强调的是“让别人研究”，不是“把结论翻译给普通用户”。

ZISO 可以借鉴它们的方法纪律，但不应该把自己产品化方向做成它们。

## 4. ZISO 的行业定位：我们真正在哪

## 4.1 用一句话说

ZISO 不是机构量化的简化版。

它是：

**把规则量化研究、参数治理和 AI 解释层结合起来，服务普通投资者动作决策的产品系统。**

## 4.2 用地图语言说

如果把地图看成二维：

1. 横轴：研究深度
2. 纵轴：面向终端用户的产品化程度

那么 ZISO 不在左下角，也不在最右上角。

它在：

**研究深度中等偏上、产品化强、执行语义强** 的区域。

### 为什么这不是低配版

因为 ZISO 解决的不是“专业研究员如何提高 Sharpe”。

它解决的是：

1. 普通投资者何时该观察
2. 何时可以出手
3. 何时必须防守
4. 为什么三种模式的动作不一样

这不是包装问题，而是目标函数不同。

## 4.3 当前仓库对应的现实坐标

从当前代码与数据库看，ZISO 已经具备 L2 的几个关键部件：

1. 规则回测主循环
   - `backend/scripts/run_min_tradeability_loop.py`
2. 每周参数校准
   - `backend/scripts/run_tradeability_weekly_calibration.py`
3. 模式参数发布物
   - `backend/scripts/build_mode_params_release.py`
   - `backend/scripts/promote_mode_params_release.py`
4. 生产模式绩效链
   - `backend/analysis/mode_pipeline.py`
5. 生产线 / 实验线分离
   - `Production Decision Lane`
   - `Research Quant Lane`

这说明我们已经不是“指标提示器”。

但同时，我们还没有完全进入 L3，因为当前还缺少：

1. 正式 benchmark 框架
2. 风险归因
3. 组合层优化
4. 容量与冲击建模
5. 完整 point-in-time universe 治理

## 5. 道法术器：ZISO 应该如何理解自己

## 5.1 道：我们到底在赢什么

“道”不是技术细节，而是你在打哪一场仗。

### ZISO 的道

ZISO 的道，不是和顶级基金争夺“谁找到更强 alpha”。

而是：

**用量化纪律，把普通投资者最容易犯的大错减少；再把少数真正值得出手的机会翻译成清晰动作。**

这意味着：

1. 我们优先优化“少犯大错”
2. 我们其次优化“抓到可执行机会”
3. 我们最后才优化“漂亮的研究指标”

如果把顺序倒过来，系统会滑向：

1. 追求回测曲线
2. 追求复杂参数
3. 追求黑盒 alpha 叙事

而这会偏离产品本质。

### 道对应的北极星

不是：

- 年化收益看起来最大

而是：

1. 模式语义长期稳定
2. 风控纪律真实起作用
3. 用户可以理解并执行
4. 研究升级能传导到产品质量

## 5.2 法：我们应该遵守什么方法纪律

“法”是方法论，不是某个指标。

对 ZISO 来说，未来必须长期坚持六条法：

1. **研究与生产分轨**
   - 实验线负责探索
   - 生产线负责稳定口径
2. **规则先于黑盒**
   - 能用白盒规则解决的，不先跳黑盒
3. **样本外优先于样本内最好看**
   - 单次最好结果不算证据
4. **成本后结果优先于理想结果**
   - 不接受只在理想成交假设下成立的结论
5. **审计优先于灵感**
   - 每一轮搜索、发布、回退都要留下结构化痕迹
6. **产品目标优先于学术炫技**
   - 所有研究都要回答：这是否真的改善了用户动作建议

这六条法，会比“是否使用了更高级模型”更决定长期方向。

## 5.3 术：当前与未来的核心术

“术”是具体打法。

### 当前已经建立的术

1. VCP-like 收缩 / 盘整识别
2. 放量突破
3. 强收盘
4. 动量确认
5. 风险 MA 否决
6. 多模式参数包
7. 每周校准与发布物治理
8. 成本分桶口径

### 下一阶段该补的术

1. anti-lookahead 检查
2. frozen universe 与 research manifest 固化
3. benchmark 对照
4. 真正路径级 drawdown
5. search audit
6. 组合视角的 mode allocation
7. 风格 / 行业 / Beta 暴露分析

### 不该急着追的术

1. 大规模黑盒信号挖掘
2. 高频或日内执行优化
3. 复杂深度学习 alpha 工厂
4. 伪机构化叙事

这些东西不是永远不做，而是当前不该优先。

## 5.4 器：支撑系统的基础设施

“器”是工具、数据、表、脚本、发布链。

对 ZISO 来说，当前最重要的器包括：

1. 本地 / 云端数据库
2. `daily_prices`
3. `quant_tradeability_signals`
4. `ai_predictions_v2`
5. `mode_decision_log`
6. `mode_simulated_trade_ledger`
7. `mode_performance_snapshot`
8. `research_pool` manifests
9. 参数 bundle / release artifact
10. 管理后台与 observability 口径

未来一年内，“器”的升级重点不该是更炫，而该是更可信：

1. 数据可追溯
2. universe 可冻结
3. 绩效定义更干净
4. 研究与生产的桥梁更一致

## 6. 我们应该去哪里：推荐路线图

## 6.1 不是去 L3 顶配，而是先去 L2.5

L2.5 是 ZISO 最合理的目标态。

### L2.5 的定义

1. 仍然是规则化、可解释、日线级
2. 仍然面向 C 端决策产品
3. 但开始具备：
   - 更正式的样本外纪律
   - 更真实的成本口径
   - benchmark 与风险归因
   - 组合层视角
   - 更可信的研究审计

### 为什么不是直接冲 L3

因为 L3 的成本，不只是多写几个模型。

它意味着：

1. 组合优化系统
2. 风险模型
3. 机构级数据治理
4. 容量与执行工程
5. 更高密度的研究组织

如果现在就按 L3 全配来设计，会把团队拖进重资产路线，反而削弱产品推进。

## 6.2 三阶段路线

### 阶段一：把 L2 做扎实

目标：

- 让当前规则研究体系从“可用”变成“可信”

重点：

1. anti-lookahead
2. search audit
3. frozen universe
4. 成本后统一目标函数
5. 研究与生产指标口径澄清

### 阶段二：进入 L2.5

目标：

- 让系统开始具备“组合与归因意识”

重点：

1. benchmark 对照
2. 风险归因
3. 模式组合建议
4. 用户池 / 市场阶段分层分析
5. 发布窗口与正式验证窗口

### 阶段三：选择性向 L3 借能力

目标：

- 借用 L3 的部分能力，而不是复制 L3 组织形态

重点：

1. 模式相关性矩阵
2. mode allocation engine
3. 轻量组合优化
4. 市场 regime-aware 参数治理

一句话说：

**不是变成机构，而是把机构最关键的纪律，抽取出来服务 C 端产品。**

## 7. 什么该坚持，什么不要碰

## 7.1 必须坚持的

1. 可解释规则优先
2. 生产线 / 实验线分离
3. 模式动作语义优先
4. 风控价值大于“神准叙事”
5. 参数治理优于灵感驱动

## 7.2 不要碰的幻觉

1. “回测好看就等于方法先进”
2. “指标更多就等于更专业”
3. “引入 ML 就自动升级”
4. “把生产模拟台账包装成真实可成交业绩”
5. “对外讲我们在做机构级 alpha 挖掘”

## 7.3 真正的护城河

ZISO 的护城河不是：

- 比所有机构更会找 alpha

而是：

1. 在 L2 规则量化上足够严谨
2. 在 C 端产品表达上足够清晰
3. 在 AI 解释层上足够有说服力
4. 在长期治理与迭代上足够稳定

这四个东西叠在一起，才是我们的真实壁垒。

## 8. 最终口径

### 8.1 对内统一口径

ZISO 正在建设的，不是一个机构式大规模 alpha 工厂。

我们在建设的是：

**一套面向普通投资者的、可解释的规则量化产品底座。**

它的核心目标不是“炫耀研究”，而是：

1. 把复杂市场压缩成动作建议
2. 把研究结果治理成可持续产品能力
3. 用量化纪律替用户挡掉一部分大错

### 8.2 对未来的统一判断

我们最好的方向不是“更像顶级基金”。

而是：

**在不失去产品灵魂的前提下，逐步吸收机构量化最有价值的方法纪律。**

### 8.3 一句话北极星

> 不追求成为最会挖 alpha 的团队，
