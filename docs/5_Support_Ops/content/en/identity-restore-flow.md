If you switch phones or reinstall, use the restore flow in User Center.

### What gets restored
- Watchlist setup
- Account identity and entitlement status
- Core user preferences tied to your account

### What to prepare
- Use the same account identity (email / restore credential).
- Complete verification prompts in the app if required.

If restore fails, wait a moment and retry with stable network. If it still fails, contact support with your account identifier and approximate restore time.
