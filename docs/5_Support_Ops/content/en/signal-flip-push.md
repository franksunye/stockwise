Signal-flip push is triggered when the action state crosses a meaningful axis, such as:

- **Observe -> Entry**
- **Entry -> Defense**
- **Defense -> Entry**

Small same-direction adjustments are usually suppressed. The goal is simple: each push should be worth opening.
