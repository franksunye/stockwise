If you are not receiving notifications, run a test push first.

### If test push fails
- Check system notification permission
- Disable battery restrictions for the app/browser shell
- Verify network stability and reconnect
- Reopen app and retry once

If test push succeeds but real alerts still fail, review category toggles in User Center.
