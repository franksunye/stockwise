You can customize alerts by category in User Center.

Core categories in v1 include:

- **Signal Reversal**: major action-state changes
- **Open / Close Briefing**: session context before and after market flow
- **Validation / Review Updates**: follow-up checks after signals
- **Watchlist Recaps**: summary-level watchlist health
- **Real-time Alerts**: paid-tier channel for intraday users who can execute during the session
- **Session Structure Radar**: available to **Go / Plus / Pro / Alpha** users; Free accounts do not receive this category

---

### Recommended setup
- Start with low-frequency categories first.
- Add Session Structure Radar only for symbols you actively trade.
- Turn off any category that causes reaction trading instead of disciplined execution.

Session Structure Radar is not a generic price broadcast. It fires only when price action reaches a support, resistance, or structural deviation condition from the plan. ZISO applies a daily cooldown per user and symbol so one repeated threshold does not keep sending the same alert.
