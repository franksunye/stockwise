For iOS, install from **Safari -> Add to Home Screen** first. Then open the app shell and enable notifications there.

If you stay in an embedded browser, system push permission may never appear.

### Quick checklist
1. Open in Safari
2. Add to Home Screen
3. Launch app from icon
4. Enable notifications in app + system settings
