# 自选股容量与资源算力计算 (Stock Quota Limits)

> *"你的关注力是有限的。当你盯着 50 个猎物时，其实你什么都没在看。"*

## 核心摘要
在 ZISO 中，你无法像使用其他券商软件一样，毫无节制地将一两百只股票塞进“自选列表”。我们对基础版和 Pro 版执行了极其严厉的“卡槽”限制。这不是单纯为了逼迫升级，这是底层哲学与工程防波堤的双重约束。

---

## 🎯 限制容量的核心哲学

### 1. 专注力收敛 (Focus Horizon)
优秀的猎手只挑选最有爆发力的非对称目标。每天被 50 只垃圾标的上下跳动干扰，会引发严重的信息过载和多动症操作。
*   **基础版 (Free Tier)** 只开放极少的 **3 个席位**。因为如果你连 3 支精挑细选的战场都驾驭不了，给你再多也是屠杀。
*   **Pro 版** 释放至 **10 个席位**（或更高专属配置），这代表着职业交易者在监控不同扇区热点时的物理极限心智承载力。

### 2. 并发大模型算力锁 (LLM Quota Lock)
不同于传统的静态指标软件，添加进 ZISO 观察库的任何一个标的，都会在后台触发一整套：
*   L1 时间序列滚动分析。
*   L2 自然语言的情绪解构 (DeepSeek-V3 并发)。
哪怕你只多挂了一只股票，系统每 5 分钟都要向其泼洒成千上万的 Token 进行推演。
因此，**自选股容量的卡槽，本质上是算力资源配额的硬分发。** 任何对服务器资源低效且贪婪的占用，在这个系统里都不被允许。
