# 三种投资偏好如何变更量化敏感度 (Investment Mode Selection)

> *"风险敞口没有对错，只有是否符合你的睡眠阈值。"*

## 核心摘要
每个人的资金体量、心理承受力和交易周期截然不同。ZISO 并不强制所有人穿同一套作战服。在系统设置中，您可以通过切换【投资偏好】，在底层动态变更系统的物理预警灵敏度与 AI 过滤宽忍值。

---

## ⚙️ 核心参数切换逻辑

### 🟢 模式一：极寒防御（Defensive / 保本优先）
*   **适用人群**：单笔投入极大，将“绝不发生回撤超 5%”视为第一铁律的用户。
*   **底层改变**：
    *   极大收缩止损阈值（如原本跌破 8% 亮红灯，此模式下变为 4%）。
    *   取消所有形态未完全确立的“左侧猜底”预测，只在结构形成极其完美的纯右侧长阳上给出入场绿灯。
    *   **代价**：会频繁被市场小震荡“洗盘”出局，并牺牲掉极大一部分鱼头/尾巴利润。

### 🟡 模式二：纪律中枢（Balanced / ZISO 默认推演）
*   **适用人群**：接受正常的市场摩擦，追求长周期盈亏比和资金复利的标准玩家。
*   **底层改变**：
    *   调用 ZISO 经过百万次模拟的最优夏普比率 (Sharpe Ratio) 参数集。
    *   容忍健康的拉回洗盘（正常回撤），只在逻辑面发生根本反转或趋势出现断头侧刀时，强行介入清仓。

### 🔴 模式三：狂战士（Aggressive / 回撤耐受极强）
*   **适用人群**：操作资金极小（仓位无足轻重），或者寻求抓极高波动妖股的小部分激进派。
*   **底层改变**：
    *   极大地拉宽滑点容忍带（在 15% 乃至 20%的巨幅波动内，AI 不会频繁干扰报警）。
    *   **重申底线**：即使在此模式下，一旦触发“流动性彻底枯竭”或“逻辑破产”的黑天鹅，ZISO 依然会跨越偏好，直接发出致命的 🔴 Kill 信号。

在设置偏好后，请勿在交易遇到阶段性阻力时随意更改。**风格漂移是量化之大忌。**
