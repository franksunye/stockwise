设了半天收不到通知？
点一下那个“测试推送”按钮。要是手机没响，那准是你的系统防火墙或者省电模式把咱给拦了。去设置里给点权限。

如果测试推送能响，但“盘中结构雷达”没有来，先确认两件事：账户是否为 Go / Plus / Pro / Alpha 付费层级，以及个人中心里这个通知类型是否开启。Free 用户不会收到盘中结构雷达。
