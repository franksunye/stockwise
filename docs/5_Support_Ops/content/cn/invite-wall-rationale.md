# 为什么设邀请墙？(Invite Wall Rationale)

> *"高精尖的风控算力，绝不向毫无准备的赌徒敞开。"*

## 核心摘要
ZISO 在内测期间不仅不对大规模流量开放，甚至设立了严苛的邀请机制与排队墙。这并不是一种“饥饿营销”，而是由于产品底层的算力极度高昂，以及我们对早期用户画像的强力清洗需求。

---

## 🧱 高墙背后的两道防线

### 1. 拦截不认同量化纪律的“巨婴”
ZISO 不是一个为你提供每日必涨“牛股代码”的算命软件。它是一个冰冷、严厉、甚至不近人情的量化执行系统。
那些带着“快速捞一笔就走”心态的赌徒群体，会在 ZISO 系统连续发出空仓静默指令时破防。通过邀请墙的发放策略，我们在物理层面上隔绝了这类需要心理按摩的高成本客群。我们需要的是拥有认知门槛、愿意用纪律换生存的职业交易者。

### 2. 算力单基极高的承载力红线
对于免费版规则引擎，ZISO 可以轻松承载百万并发。
但系统为 C 端调用的，是能够实时下钻研报、交叉验证情绪的顶级大语言模型 (如 DS-V3)。单次深度推演所消耗的 AI Token 是惊人的。
开放大门任由爬虫和羊毛党涌入，会瞬间击穿我们的 API 预算阀值，导致真正的核心用户感受到任何一丝延迟。

这违背了我们对延迟“零容忍”的根基协议。

**结论**：高墙是为了保护城内的生态。在算力与商业模式完全自平衡之前，ZISO 的大门将只为同序列的战友而开。
