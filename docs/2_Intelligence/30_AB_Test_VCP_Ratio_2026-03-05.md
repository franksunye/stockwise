# A/B 实验记录：VCP 阈值单参数测试（0.8 vs 0.9）

**文档状态**: Draft  
**分支**: `exp/quant-ai-tradeability-v1`  
**日期**: 2026-03-05  
**作者**: Codex  
**目标**: 仅调整 `VCP-like` 阈值（`vcp_ratio`），验证覆盖率提升是否可在风险可控下维持正期望。

---

## 1. 实验设置

固定条件：

1. 数据：`data/stockwise.db`，`2024-01-01` 至 `2026-03-05`  
2. 规则：`Watch -> TriggeredLong -> RiskOff`  
3. 退出：`stop_loss=6%`、`close<ma10`、`max_hold_days=10`  
4. 对照：`MA20` 基线 + `3` 窗口 walk-forward

唯一变量：

1. A 组：`vcp_ratio=0.8`  
2. B 组：`vcp_ratio=0.9`

结果文件：

1. `tmp/min_tradeability_loop_vcp08.json`  
2. `tmp/min_tradeability_loop_vcp09.json`

---

## 2. 全样本 A/B 对比

### 2.1 机会覆盖与触发

1. `watch_coverage`: `0.744% -> 1.688%`（提升约 `2.27x`）  
2. `trigger_coverage`: `0.232% -> 0.631%`（提升约 `2.72x`）  
3. `trade_count`: `29 -> 77`

### 2.2 收益与风险

1. `expectancy`: `+5.36% -> +2.38%`（下降，但仍为正）  
2. `payoff`: `4.36 -> 3.16`（下降，但仍 > 1.3）  
3. `max_drawdown`: `35.25% -> 51.43%`（上升）

### 2.3 短线命中

1. `T+1 win_rate`: `41.38% -> 42.86%`（小幅提升）  
2. `T+3 win_rate`: `28.57% -> 40.79%`（明显提升）

---

## 3. Walk-forward（三窗口）对比

`vcp_ratio=0.8`：

1. W1 `exp=+14.60%`  
2. W2 `exp=-2.99%`  
3. W3 `exp=+3.68%`

`vcp_ratio=0.9`：

1. W1 `exp=+6.97%`  
2. W2 `exp=-1.67%`  
3. W3 `exp=+2.19%`

结论：

1. 两组都出现窗口 2 失效，说明仍有 regime 敏感性。  
2. `0.9` 组覆盖更高、样本更大，利于后续稳定评估。  
3. `0.9` 组回撤更高，需要下轮先做风险收敛。

---

## 4. 对照验收标准（27 文档）

相较 `0.8`，`0.9` 的变化：

1. “触发太少”问题得到明显缓解（方向正确）。  
2. `T+3` 胜率提升，但仍未达 `52%`。  
3. 期望值保持为正，但回撤变大。

当前判定：**B 组（0.9）更适合作为下一轮起点**，因为它先解决了“无交易样本”的核心瓶颈。
