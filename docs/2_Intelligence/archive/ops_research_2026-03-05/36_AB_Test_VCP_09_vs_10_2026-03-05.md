# A/B 实验记录：VCP 阈值（0.9 vs 1.0）

**文档状态**: Draft  
**分支**: `exp/quant-ai-tradeability-v1`  
**日期**: 2026-03-05  
**作者**: Codex  
**目标**: 在当前主参数上，仅放宽 `vcp_ratio`（0.9 -> 1.0），评估覆盖率提升的代价。

---

## 1. 实验设置

固定参数：

1. `stop_loss_pct=0.05`  
2. `max_hold_days=10`  
3. `risk_off_ma=10`  
4. `breakout_volume_mult=1.1`  
5. `strong_close_threshold=0.65`  
6. `momentum_change_threshold=4`

变量：

1. A：`vcp_ratio=0.9`  
2. B：`vcp_ratio=1.0`

---

## 2. 全样本对比

`VCP0.9`：

1. `trigger_cov=1.502%`  
2. `T+3=46.55%`  
3. `expectancy=+3.34%`  
4. `payoff=3.79`  
5. `MDD=44.16%`  
6. `trades=175`

`VCP1.0`：

1. `trigger_cov=2.858%`  
2. `T+3=48.38%`  
3. `expectancy=+2.91%`  
4. `payoff=3.60`  
5. `MDD=56.84%`  
6. `trades=310`

---

## 3. Walk-forward（三窗口）

`VCP0.9` 期望：`+3.16 / +1.96 / +3.13`，回撤：`18.77 / 42.74 / 55.12`  
`VCP1.0` 期望：`+2.46 / +1.01 / +2.54`，回撤：`26.04 / 67.21 / 58.71`

结论：

1. `VCP1.0` 覆盖率显著提升，但风险代价较大（尤其窗口 2 回撤）。  
2. `VCP0.9` 在风险收益平衡上更稳健。  
3. 若以“达标优先”为目标，建议保留 `VCP0.9` 作为主版本。

---

## 4. 双轨建议

1. **主版本（稳健轨）**：`vcp_ratio=0.9`  
2. **探索版本（覆盖轨）**：`vcp_ratio=1.0`

用途：

1. 稳健轨用于持续评估与后续上线候选。  
2. 覆盖轨用于研究如何接近 `coverage >= 5%`，但需更强风控后再考虑上线。
