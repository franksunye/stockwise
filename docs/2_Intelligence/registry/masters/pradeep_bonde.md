# Pradeep Bonde (Stockbee)

> **“现代动量交易的布道者，Episodic Pivot (EP) 与 4%/20% 突破规则的奠基人。”**
>
> 邦德（Stockbee）以其对市场动能的深刻洞察著称，将复杂的量价分析简化为极具可操作性的“事件拐点”与“20日线平仓”等硬性规则，是全球无数动量交易者的实战指引。

## 核心价值

1. **Episodic Pivot (EP)**：利用重大基本面催化剂导致的“爆发点”捕捉长期趋势。
2. **ADR (Average Daily Range)**：专注于高波动、高爆发力的个股（ADR > 4%）。
3. **4% / 20% Breakout**：量化入场标准，即价格突破当日 > 4% 或近 5 日累计 > 20%。
4. **大样本博弈**：强调通过大量符合标准的交易来实现统计优势。

## 对 StockWise 的意义

1. **Momentum 动量源流**：为我们的动量策略提供最简洁、最高效的入场标准（EP）。
2. **波动率选股**：引入 ADR 概念来过滤“僵尸股”。

## 典型工具/规则

- **EP 识别**：单日成交量爆炸（通常前 1% 或 >10x 均量）+ 价格大幅跳空且收高。
- **20-day / 50-day Moving Average**：作为主要动态支撑位。
