# Mark Minervini

> **“两届全美投资冠军，《股票魔法师》系列作者，SEPA® 体系的灵魂人物。”**
>
> 米勒维尼以其极高盈亏比的特定的入场点分析（SEPA®）体系称雄华尔街，通过识别波动冷缩形态（VCP）来捕捉机构吸筹后的爆发点，是现代成长股趋势交易最具影响力的导师之一。

## 核心价值

1. **SEPA® (Specific Entry Point Analysis)**：结合基本面与技术面的系统化选股与入场分析法。
2. **VCP (Volatility Contraction Pattern)**：识别机构吸筹与波动冷缩的图形结构。
3. **Trend Template™ (Stage 2)**：严格的趋势模板，只交易处于上升第二阶段的股票。
4. **绝对风险管理**：将止损设定在 7-8% 以内，甚至更紧，追求极佳的盈亏比。

## 对 StockWise 的意义

1. **Layer-1 核心算法来源**：我们的 `Watch`、`TriggeredLong` 状态机直接借鉴了 VCP 的枢轴位突破逻辑。
2. **纪律化引擎**：系统强制执行“二阶段”趋势过滤，避免 AI 在弱势行情中频繁出手。

## 典型工具/规则

- **VCP 结构识别**：寻找 2-4 轮波动收缩（T1, T2, T3...）。
- **Pivot Point 突破**：寻找波动最低、筹码最稳时的极点突破。
