# 大师系列月度内容规划（NotebookLM + PPT）

## 1. 这件事的目标，不只是做 20 份 PPT

这套内容更适合被定义为一条可复用的知识栏目，而不是一次性选题。

目标应是：

1. 用 `NotebookLM` 把分散的研究资料整理成可追溯、可复核的“知识包”
2. 每位大师输出 1 份短文字、强结构、可跨平台复用的 PPT
3. 同一份底稿同时服务：
   - 小红书图文 / 卡片
   - 公众号长图文或轻长文
   - 后续站内 Academy / Registry / Support 解释内容
4. 所有内容都回到 StockWise 的统一边界：
   - 不神化人物
   - 不把大师直接包装成“荐股模板”
   - 强调方法、纪律、适用边界与经典源流

一句话：

**我们做的不是“大师崇拜”系列，而是“量化世界观与方法源流”系列。**

---

## 2. 推荐栏目定位

### 栏目名方向

可选其一：

1. `交易大师图鉴`
2. `量化门派图谱`
3. `大师方法课`
4. `投资世界的 20 位老师`

如果面向小红书和公众号同时兼容，我更建议用：

**`交易大师图鉴`**

原因：

1. 对小红书更友好，天然适合做系列封面
2. 对公众号也足够稳，不会太像短视频标题党
3. 既能装人物，也能顺带装方法、纪律和门派

### 内容定位

推荐归类为：

- 漏斗：`TOFU -> MOFU`
- 节奏：`Hub`

作用不是直接转化，而是：

1. 建立“你们真的懂量化世界”的认知
2. 把 StockWise 的方法来源讲清楚
3. 为后续 L2、决策栈、风险纪律内容做桥梁

---

## 3. 内容结构建议：不要只做“5 类 x 5 个”

如果直接按 `5 类 x 5 个 = 25 个` 硬凑，容易出现两个问题：

1. 有些人物对 StockWise 关系并不强，做多了会稀释主线
2. 人物太多时，系列会从“知识体系”滑向“人物百科”

更稳的做法是：

**先定 20 个主选题，再保留 5 个备选题。**

推荐结构：

1. `5 个核心大师`
2. `5 个方法体系`
3. `4 个策略原型`
4. `3 个风险与执行纪律`
5. `3 个世界观与架构桥梁`

这样一共 `20` 个主选题，既完整，也更容易在一个月内完成。

## 4.7 如果目标是“经得起行业和专家考验”，当前清单够不够全

结论先说：

**现在这份 `20` 题框架，已经够做成一条很好的长青系列，但如果目标是“经得起行业和专家考验的经典母题全集”，还不够全。**

原因不是现在这 `20` 题不对，而是它们更偏：

1. 趋势 / 动量 / 规则交易主线
2. 更贴近当前 StockWise 的研究兴趣
3. 适合快速建立第一轮系列

但如果要更像“行业经典母题库”，还必须补上几类真正绕不过去的根基人物和出版物母题。

### 为什么说还不够全

从中文出版物和长期流传度看，真正反复出现、并且跨代际被讨论的经典母题，大致会集中在这些簇：

1. `价值投资根基`
   - 本杰明·格雷厄姆
   - 《聪明的投资者》
   - 《证券分析》
2. `价值成长桥梁`
   - 菲利普·费雪
   - 《怎样选择成长股》
3. `成长股 / CAN SLIM`
   - 威廉·欧奈尔
   - 《笑傲股市》
4. `投机 / 交易心理原型`
   - 杰西·利弗莫尔
   - 《股票作手回忆录》
5. `系统交易与仓位管理`
   - 范·撒普
   - 《通向财务自由之路》
6. `经典交易人物口述史`
   - 杰克·施瓦格
   - 《金融怪杰》《新金融怪杰》

换句话说，当前这份清单的强项，是：

1. `趋势 / 动量 / 规则交易`
2. `成长股右侧交易`
3. `风险纪律与执行`

而它当前偏弱、但专家很容易追问的几条主干，是：

1. `价值投资根基`
   - 格雷厄姆没有进入主清单
2. `成长股经典根基`
   - 费雪、欧奈尔都还没进入主清单
3. `经典投机与价格行为源头`
   - 利弗莫尔、威科夫都还没进入主清单
4. `仓位管理与系统开发`
   - 范·撒普还没进入主清单
5. `行业共同记忆文本`
   - 《金融怪杰》系列还没有被明确提升为桥梁母题

所以，如果专业读者站在“投资与交易经典全景图”的角度来挑，这份 `20` 题会被评价为：

**方向对，质量也可以，但仍偏向 StockWise 当前偏好的交易支脉，而不是更完整的行业经典谱系。**

### 外部锚点为什么支持这个判断

这里不靠主观感觉，而看长期出版与行业文本的硬信号：

1. `HarperCollins` 仍把《聪明的投资者》定位为价值投资的决定性经典
   - 来源：https://www.harperacademic.com/book/9780060854300/the-intelligent-investor
2. `Wiley` 仍把埃尔德的《新以交易为生》作为现代交易经典持续发行
   - 来源：https://newsroom.wiley.com/press-releases/press-release-details/2014/The-New-Trading-for-a-Living-by-Dr-Alexander-Elder/default.aspx
3. `William O'Neil` 官方遗产站仍把 `CAN SLIM` 作为其核心创新来叙述
   - 来源：https://wjolegacy.williamoneil.com/
4. `Minervini` 官方站仍把其“两届美国投资大赛冠军”与书籍体系作为核心身份锚点
   - 来源：https://mtp.minervini.com/
5. 中文世界里，豆瓣长期有稳定讨论、再版与高识别度的经典书，集中落在：
   - 《聪明的投资者》：https://book.douban.com/subject/5243775/
   - 《笑傲股市》：https://book.douban.com/subject/4244804/
   - 《通向财务自由之路》：https://book.douban.com/subject/2382899/
   - 《股票大作手回忆录》：https://book.douban.com/subject/10617312/
   - 《金融怪杰》：https://book.douban.com/subject/30273539/

这些外部锚点共同说明：

**行业长期记忆，不是只由“最近几年谁更火”决定，而是由“哪些书、哪些人物、哪些系统在 10 年、20 年、30 年后还在被反复出版、反复提起”决定。**

如果这些簇完全不进入系列，专业读者很容易觉得：

**你们这套图鉴很强，但更像“趋势动量分支图谱”，还不是“投资与交易经典全景图谱”。**

### 中文出版物层面的强信号

下面这些书在中文世界都存在稳定传播和持续再版讨论，是很强的“行业认可”信号：

1. 《笑傲股市》
   - 威廉·欧奈尔与 `CAN SLIM` 在中文投资圈长期有稳定影响
   - 来源：https://book.douban.com/subject/4244804/
2. 《怎样选择成长股》
   - 菲利普·费雪是成长股投资根基人物之一
   - 来源：https://book.douban.com/subject/20504695/
3. 《巴菲特致股东的信》
   - 巴菲特长期文本母本
   - 来源：https://book.douban.com/subject/1046164/
4. 《通向财务自由之路》
   - 范·撒普在仓位与系统开发领域影响深
   - 来源：https://book.douban.com/subject/2382899/
5. 《股票作手回忆录》
   - 中文交易圈常青经典
   - 来源：https://book.douban.com/subject/10462475/
6. 《金融怪杰》《新金融怪杰》
   - 交易人物口述史母本
   - 来源：https://book.douban.com/subject/11509654/
   - 来源：https://book.douban.com/subject/30151832/

### 因此，更稳的做法不是停在 20 题

更稳的结构应该是：

1. `总盘子：35 个行业级母题`
   - 作为这条线长期完整的知识地图
2. `首发：前 20 题`
   - 作为第一轮对外发布清单
3. `扩展：后 15 题`
   - 用来补齐经典根基、经典方法与行业共同记忆

## 6. 每份 PPT 的标准结构

不建议每个主题都做成长篇讲义。

更适合统一为 `8` 页社媒型极简 PPT：

1. `它是谁 / 它是什么`
2. `它到底牛在哪里`
3. `最容易被误解的地方`
4. `关键术语`
5. `核心观点一`
6. `核心观点二 / 它解决什么问题`
7. `今天为什么还有这么多人讲它`
8. `一句总结`

硬约束：

1. 每页只承载 `1` 个核心信息点
2. 每页文字尽量控制在 `20-60` 字
3. 不要把一页做成小文章
4. 优先服务视觉传播，不追求一次讲全

这个结构的好处是：

1. 适合 NotebookLM 自动整理
2. 适合转成小红书多页图卡
3. 适合转成公众号配图或轻长文
4. 后续更容易批量生产

---

## 7. 每份内容的文字原则

你已经说得很对：**文字要短，但要客观、事实确凿。**

建议把每页文字控制在：

- 标题：`8-16` 字
- 正文：`40-90` 字
- 最长不超过 `120` 字

写法上坚持 4 条：

1. `先事实，后评价`
2. `先方法，后传奇`
3. `先边界，后推崇`
4. `先讲他留下了什么，后讲他有多传奇`

特别注意：

- 不要写成鸡汤式“大师名言摘抄”
- 不要写成“跟着他买就能赢”
- 不要把有争议的细节写成确定事实
- 一切最终都回到“方法论输入”

## 8. NotebookLM 的最佳使用方式

不要让 NotebookLM 直接“写 PPT 成品”。

更推荐把它当成三件工具：

1. `资料压缩器`
2. `事实核对器`
3. `统一口径整理器`

### 推荐工作流

1. 为每个主题建一个 `NotebookLM Notebook`
2. 每个 Notebook 只放一位大师或一个方法体系的源资料
3. 资料源优先级建议：
   - 已有 `registry` 卡片
   - 已有 `0_Strategy` 文档
   - 官方书籍摘要 / 官方采访 / 官方网站
   - 高质量二手总结
4. 先让 NotebookLM 输出：
   - `10 条可确认事实`
   - `3 条最重要观点`
   - `3 条常见误解`
   - `StockWise 可吸收的 2-3 点`
5. 再由人工把结果改写成 PPT 页面文案

### 最关键的一条

**NotebookLM 负责“整理事实”，不要让它直接决定“我们怎么表述产品立场”。**

产品立场必须回到：

- `docs/2_Intelligence/registry/README.md`
- `docs/0_Strategy/06_Quant_Industry_Positioning_Map.md`
- `docs/0_Strategy/09_Decision_Stack_and_Producer_Architecture.md`
