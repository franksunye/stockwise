# StockWise 工程 Backlog (增量升级看板)

此文件用于追踪后端的重构与优化进度。每一项任务必须保证 **“功能等效”** 且通过 **“等效性验证”** 后方可勾选。

## 核心原则
1. **小步快跑**: 每次只改动一个逻辑点。
2. **双轨验证**: 高风险改动需支持 `_legacy_` 函数对比。
3. **零 Any**: 所有新定义的模型和标注严禁使用 `any`。
