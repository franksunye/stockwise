# MACD：动能之王，如何识别趋势的加速与衰竭？

> *"新手看价，老手看量，高手看势 (MACD)."*

MACD (Moving Average Convergence Divergence) 通常被称为"指标之王"。
但 99% 的人只会看"金叉买，死叉卖"。
如果你这么用，在震荡市里你会左右挨耳光，脸都被打肿。

MACD 真正看的不是方向，而是 **速度 (Velocity)** 和 **加速度 (Acceleration)**。

---

## 1. 物理学视角：DIF 与 DEA

把股价想象成一辆正在行驶的赛车。

*   **0 轴**：地平线。水上是多头世界，水下是空头世界。
*   **DIF (快线)**：赛车当前的**速度**。
*   **DEA (慢线)**：赛车过去一段时间的**平均速度**。
*   **MACD 红绿柱**：**加速度**（油门深浅）。

### 金叉的真相
当 DIF 上穿 DEA（金叉）时，意味着**"当前速度 > 平均速度"**。
如同你在高速公路上超车。这意味着趋势在**加速**。

### 红绿柱的秘密
红柱子在变长，说明**加速中**（推背感很强）。
红柱子开始变短，说明**虽然还在加速，但推背感减弱了**（开始松油门了）。

---

## 2. 也是背离：最昂贵的信号

在 StockWise AI 的权重体系里，**MACD 顶/底背离** 是权重最高的技术信号之一（仅次于量价结构）。

**什么是顶背离？**
股价创了新高（车速到了 200km/h），但 MACD 红柱子的面积却比上一波小（油门已经没踩到底了，只有一半）。

这在物理学上意味着什么？
这意味着你在靠**惯性**冲刺。这通常是动能耗尽的前兆。
一旦惯性消失，重力（获利盘）就会瞬间接管，这就是为什么顶背离之后往往伴随着**暴跌**。

---

## 3. StockWise 的"零轴战法"

我们的 AI 尤其关注 MACD 与 **0 轴** 的关系。这是判断趋势健康度的关键。

### A. 零上金叉 (The Re-ignition)
*   **形态**：DIF 和 DEA 都在 0 轴上方（多头市场），DIF 回调不破 0 轴，再次金叉向上。
*   **含义**：这是**"空中加油"**。多头趋势极强，仅仅休息了一下，现在二次点火发射。
*   **AI 建议**：**Strong Buy**。这是主升浪中最肥美的一段。

### B. 水下金叉 (The False Hope)
*   **形态**：DIF 和 DEA 都在 0 轴下方（空头市场）发生金叉。
*   **含义**：这只是**"反弹"**，不是反转。上面有重重的套牢盘压力（海平面压力）。
*   **AI 建议**：**Side / Short**。除非伴随巨量突破 0 轴，否则 AI 会将其视为诱多陷阱。

---

## 4. 给散户的忠告

下次看 MACD，忘掉"金叉死叉"。
盯着那个**柱状图 (Histogram)**。

*   当股价在涨，但红柱子一波比一波矮时：**快跑**。你的车已经没油了。
*   当股价在跌，但绿柱子一波比一波短时：**盯住**。空头已经累了，反击随时可能开始。

MACD 是透过价格表象，看穿市场内部动能的 X 光机。
