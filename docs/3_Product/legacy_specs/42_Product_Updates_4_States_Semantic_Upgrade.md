## 摘要 (Executive Summary)

为给用户提供更清晰、不纠结的交易指引，知守 AI (ZISO AI) 近期完成了一次极其底层的架构与语义大焕新。
我们将深奥的量化指标与 AI 分析，提纯成了普通投资者“一眼即懂”的四种持仓状态；并在系统架构上实现了“产品生产”与“量化实验”的双轨分离。这一改变意味着：你看到的建议将越来越稳，而 AI 后台的进化将越来越快。

以下是本次升级的核心支持内容释义。

---

## 1. 极简降噪：“四态”语义模型正式上线

在过去的版本中，我们向前端透出了大量如“突破放量”、“VCP比率”等晦涩的量化过程指标。但在真实的交易中，投资者最需要知道的是“我到底该做什么”。
为此，我们将由 Layer-1 状态机裁决的量化信号，转化为了直击灵魂的**四大交易状态**：

| 量化状态 (Layer-1) | 界面显示文案 | 核心释义与交互反馈 | 应对策略 |
| :--- | :--- | :--- | :--- |
| `TriggeredLong` | **建议进场** | 红色（上涨色）Badge：“适合开始寻找机会” | 标的走势已经触发了系统的最优狙击标准，此时建仓的胜率具有较强的数学支持。 |
| `Watch` | **建议观察** | 黄色（持平色）Badge：“先观察，不急着出手” | 标的处于震荡或等待突破的形态中，暂未满足进场条件，不盲目操作，列入重点监控。 |
| `RiskOff` | **建议防守** | 绿色（下跌色）Badge：“优先控制风险” | 盘面已出现资金出逃或趋势破坏迹象。不要新增仓位；已有仓位应严格评估止损。 |
| `NoSetup` | **暂无信号** | 灰色（静默色）Badge：“当前不建议出手” | 标的毫无波澜或处于持续下行通道，没有任何值得出手的逻辑，保持场外休息状态即可。 |

**为什么我们需要这四个状态？**
因为**方向裁决**现在彻底交给了稳定的量化规则（Layer-1），而大语言模型（LLM / AI）则退居至 Layer-2，仅作为“战术解释员”。
**好处是：** 系统的方向输出（买、卖、看）变得极其具备连贯性和确定性，彻底杜绝了以前“AI 看心情时常变脸”的情况，实现了“铁打的纪律，灵活的解释”。

---

## 2. 交易视角的 UX / UI 语言大洗牌

除了四大主状态外，我们全量洗刷了整个产品界面的文案，使其100%匹配专业交易员和真实市场的思维模型（Mental Model）：

- **从“结构化关键价位”到“核心操盘点位”**：不再用死板的数据术语，而是告诉你这就是操盘时的锚。
- **从“场景建议”到“交易预案”**：交易不是看风景，而是带着预案上战场。
- **从“解析 AI 推理逻辑”到“查看策略推演过程”**：去除了原有的“AI技术味”，强调系统是在进行严谨的策略博弈。
- **从“监控”到“自选”**：回归用户最熟悉的股票术语。
- **空间感优化**：我们在价格图表节点增加了微妙的上/下位移指示图标，在战术卡片中增加了语义色彩，极大地降低了认知摩擦。符合 *Silent Math* (静默数学) 的品牌极简风格。

---

## 3. 双轨驱动：更稳健的产品池，更激进的研究池

这是本次更新的幕后英雄。我们实施了严密的 **Dual-Lane 架构（生产链路 vs 研究链路）**：

- **生产链路（Production Lane）**：即用户每天在页面刷到的东西。它运行在极其苛刻的准入条件下，只输出被绝对验证过的信号，追求极度的“稳”。
- **研究链路（Research Lane）**：这是给我们的研发量化跑的实验场（涵盖 `tradeability_sidecar` 和 `shadow universe` 影子宇宙扩样）。在这条看不见的轨道里，AI 会用不同的指标组合跑上百只潜在股票，进行激进的优胜劣汰测算。一旦新策略跑通（例如连续数周跑赢大盘回撤极小），审核通过后，研究链路的结论才会平滑且无痕地切换到生产链路。

**对用户的价值：** 你们永远在使用最“稳定、健康”的交易决策模型，而不需要成为不成熟量化策略的小白鼠，享受着系统的平滑进化（Silent Upgrades）。

---

## 4. “投资模式”的组件化与动态重构

为了提升个性化设置的流畅度，我们在用户侧针对 **Investment Mode (投资模式配置)** 进行了大刀阔斧的底层优化：

1. **真实数据映射**：过去的模式切换存在数据不通畅。现在抽屉式菜单（User Center Drawer）中，你的风险承受等级、默认时间窗口已经实现了与后端真实 API 的打通。
2. **沉浸式交互（Accordion 伸缩）**：把原本繁琐的配置项打包进了一个优雅的动态手风琴组件内。你不用跳出页面，只需一点即可展开/折叠你的策略配置，伴随“乐观 UI（Optimistic UI）”的响应，所有配置更新均实现了真正的“丝滑无感”。

---

## 5. 即将开启的邀请制体验 (Invitation Ops)

由于计算资源的稀缺与策略容量的保护，新的 Admin 策略后台同步上线了 **邀请码分发系统 (Invitation Management)** 。
未来新用户的入场将严格遵循邀请控制（按 10天, 15天, 30天, 60天, 90天分类发放权限），不仅保障了社区的克制氛围，也避免了大量短期套利者的涌入，确保每一位 PRO 用都能享受到最满格的算力支持。
