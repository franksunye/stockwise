# StockWise "Silent Math" 视觉系统与游戏化增长方案

> **代号**: Project Muse (灵感缪斯)
> **核心哲学**: 数字是冰冷的事实，视觉是温暖的直觉。将复杂的量化指标“叙事化”，让投资成为一种具备美感和规律的生活方式。

---

## 一、 核心产品理念：两级“黄历”系统 (Two-Tier Almanac System)

我们将复杂的量化与市场环境数据“叙事化”，重构为每天发行的“投资黄历”。
黄历分为**市场级 (Macro)** 和 **个股级 (Micro)** 两套视觉生成体系。

### 1. 市场黄历 (Market Almanac) - [规划中]
每天早晨/盘后生成的一张全局性海报，基于宏观上下文（大盘成交额、板块资金流向、大盘均线状态）。
*   **全局气象 (Macro Mood)**：例如“倒春寒” (量缩底背离)、“烈火烹油” (连续万亿成交额)。
*   **今日总纲 (Macro Strategy)**：比如“宜：轻仓防守”、“忌：追高连板”。
*   **板块资金风向 (Capital Flow)**：将资金的板块轮动隐喻为“风向与洋流”。不再展示繁杂的红绿热力图，只提取 Top 2 净流入与 Top 1 净流出作为“阵眼”。
    *   **风口聚变**：资金高度一致流向主线（如：“百川归海”、“势如破竹”，视觉呈现为粒子向特定焦点汇聚）。
    *   **暗流涌动**：高低位板块切换，资金搬家（如：“移花接木”、“枯木逢春”，视觉呈现为能量色彩的平滑转移）。
    *   **混沌乱流**：电风扇行情，题材无序轮动（如：“乱花迷眼”、“卷起千堆雪”，视觉呈现为无序杂乱的涟漪或风场线）。
*   **动态展示**：基于大盘指数和资金流向的 `context` 数据生成宏观意境。

### 2. 个股黄历 (Stock Almanac) - [✅ 已上线 v1.2]
将深度分析反哺到极简网页海报中，作为个股行动纲领。
*   **视觉意境 (Token & Mood)**：已实现（例如“静水深流”、“能量涌现”）。
*   **关键点位 (Key Levels)**：将 API 中的阻力位/支撑位转化为黄历的“阵眼”。
*   **天机情报 (Intelligence)**：从 AI 分析中提取核心逻辑。
*   **针对性策略 (Tactic)**：根据用户仓位状态自动匹配操作建议。

## 二、 核心技术亮点 (Implementation Highlights)

### 1. 智能自适应缩放引擎 (Auto-Scaling Engine)
- **原理**：基于视口高度实时计算 `scale` 系数 (0.75x - 1.0x)，锁死 `aspect-ratio`。
- **优势**：确保在 iPhone SE 到 Pro Max 之间，海报内容永远完整且核心按钮可见。

### 2. 高保真图像导出 (Hi-Res Capture Logic)
- **像素回正**：生成图片时重置缩放为 1.0，确保输出为 Retina 级别高清图。
- **元素过滤**：使用 `capture-hidden` 样式过滤掉 UI 交互按钮。

### 3. 社会化营销闭环 (Marketing Loop)
- **文案生成器**：一键生成适配朋友圈/小红书的脱敏结构化文本。
- **一键快捷操作**：集成 [分享意境]、[复制文案]、[保存图片] 三位一体。

## 三、 视觉规范 (Aesthetic Standards)

### 1. 3层字阶系统 (3-Tier Scale)
*   **Large (4xl)**: 用于时间与意境标题。
*   **Medium (xl/sm)**: 用于主数据位与股票信息。
*   **Small (10px)**: 用于标签、水印、版权。

### 2. 单色调艺术逻辑 (Monochrome First)
*   除了**决策信号**保留红绿语义外，数据块均采用低饱和度灰阶 + Backdrop Blur，提升高级感。
