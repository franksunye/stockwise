# StockWise "Silent Math" 视觉系统与游戏化增长专项方案 (Conceptual Spec)

> **版本**: v1.0
> **代号**: Project Muse (灵感缪斯)
> **核心哲学**: 数字是冰冷的事实，视觉是温暖的直觉。将复杂的量化指标“叙事化”，让投资成为一种具备美感和规律的生活方式。

---

## 一、 核心产品理念：投资“黄历” (The Investment Almanac)

不再直接扔给散户 RSI=30 这种枯燥数据，而是通过 AI 将其翻译为具备“交易直觉”的传统黄历语义。

### 1. 语义映射逻辑 (Logic to Metaphor)
| 量化指标脉冲              | 传统/直觉倾向语境 | 建议视觉隐喻                           |
| :------------------------ | :---------------- | :------------------------------------- |
| **MACD 金叉 + 底背离**    | **宜：顺风起帆**  | 动态风车、充电进度条 (Energy Charging) |
| **RSI > 80 + 缩量滞涨**   | **忌：贪海无涯**  | 红色报警预警、破碎的玻璃感             |
| **成交量极度萎缩**        | **静：深水潜伏**  | 晨雾、极简的水平线脉冲                 |
| **回测胜率 > 80% (共振)** | **吉：良辰吉日**  | 核心光晕、共振波动圈                   |

---

## 二、 执行策略：低侵入性解耦 (Conservative Overlay Strategy)

为了保持应用初期的专业性与稳定性，本专项采取“外挂/插件”式开发逻辑，不改变核心交易逻辑。

### 1. 逻辑解耦 (Sidecar Engine)
*   核心 `QuantEngine` 保持现状，输出标准 JSON。
*   `MetaphorEngine` 作为 **副作用接口 (Side Effect API)**，为前端提供可选的 `visual_story` 字段。若前端不调用，主流程零感知。

### 2. UI 零干扰原则 (Safe UI Interaction)
*   **入口收口**：取消全屏强制遮罩，改为 **“浮窗/抽屉内部组件”**。
*   **模式切换**：在个人设置中增加 `极简专业/直觉艺术` 切换开关，默认为极简专业。

---

## 三、 视觉语言系统 (Silent Math Style Guide)

### 1. 能量与节奏 (Energy & Rhythm)
*   **微动效图标**: 将卡片中心的静态 `Zap` 图标换为与其相同占位的“呼吸符号”，不改变布局。

### 2. 气象隐喻 (Mood Weather)
*   仅在“战报分享”海报中全量开启，App 内部仅作为辅助背景色提示。

### 3. 长图渲染引擎 (Aesthetic Poster)
*   建立一套 **“低饱和度、高留白、德系工业风”** 的海报模板。
*   用户一键生成的分析结果，看起来更像是一张“咖啡馆海报”而非“证券报告”。这种“去金融化”的视觉处理，是进入高端社交圈的关键。

---

## 四、 专项执行路径 (Refined Q2 Roadmap)

1.  **[v4.1] 后端语义侧链 (Metaphor Sidechain)**: 在不影响现有 API 结构的前提下，通过 `extra_info` 注入语义字段。
2.  **[v4.2] 艺术式分享插件 (Aesthetic Sharing Plugin)**: 优先开发“生成分享图”功能。这是一项 **非侵入式功能**，不触碰 Dashboard 核心路由。
3.  **[v4.3] 可选的“直觉模式”开关**: 实现 UI 控制逻辑，让用户主动选择是否开启“视觉叙事”。

---

## 五、 长期意义
Silent Math 不仅仅是换个皮肤，它是在**重塑用户的感知方式**。通过这种“游戏化且高级”的体验，StockWise 将从众多的量化软件中脱颖而出，变成一个具备**品牌溢价**的投资生活方式入口。
